# 루멘 파티 추가 칸 5종

내장 image_gen으로 제작한 PNG 원본입니다. 평면 팔각형이며 바깥 영역은 투명합니다.
각 파일 크기는 1254 × 1254 px입니다. PNG에 칸 이름이나 효과 설명을 넣지 않았습니다.

- camp-shared.png: 공용 거점. 중립적인 회색 바탕, 집·결정·공동 사용자 문양. 소유자 번호 없음.
- transfer-vermilion.png: 교체 · 버밀리언.
- transfer-magenta.png: 교체 · 마젠타.
- transfer-cobalt.png: 교체 · 코발트.
- transfer-slate.png: 교체 · 회청색.

교체 문양은 윗줄이 오른쪽, 아랫줄이 왼쪽을 가리키는 두 단방향 화살표입니다.
연결된 교체 지점 두 곳에 같은 색 PNG를 사용하세요.
플레이어의 주황(#FFC775)·시안(#72D8ED)·라벤더(#C9A1FF)·민트(#8CE1BD)와 다른 색상으로 구성했습니다.
생성 프롬프트의 색상 코드는 목표색이며, 생성된 PNG의 각 픽셀 값은 미세하게 다를 수 있습니다.

preview.html은 다섯 이미지와 64 px 축소 미리보기를 보여 줍니다.
manifest.json에는 파일명, 정적 경로, 크기, 체크섬이 있습니다.
generation-plan.json에는 사용한 전체 프롬프트와 참조 이미지 경로가 있습니다.

프로젝트 저장 위치: LumenGG/static/v2/party-icons/v2/

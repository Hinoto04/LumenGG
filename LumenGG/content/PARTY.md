# 루멘 파티

웹 `/battlelog/party/` 또는 모바일 앱의 **루멘 파티**에서 2~4명이 방을 만듭니다. 로그인 없이 방 코드나 초대 링크로 참여합니다. 카드와 패는 오프라인 테이블에서 관리하고 지도와 계산기는 서버로 동기화합니다.

## 실행과 배포

새 배포에는 `python manage.py migrate`가 필요합니다. `0030`은 파티 모델을, `0031`은 누적 FP 저장 범위 변경을 적용합니다. `0032`는 카드 21장의 문구·이미지 경로·설명란 좌표를 DB에 등록합니다. 검증은 `python manage.py test battlelog.test_party battlelog.test_party_rules battlelog.test_party_roll battlelog.test_party_arrival battlelog.test_party_expanded battlelog.test_party_cards --settings=LumenGG.test_settings`로 실행합니다. 기존 회귀 테스트는 저장된 1판 지도를, 확장 테스트는 기본 2판 지도와 자동 전환을 검증합니다. 앱에는 Expo SDK에 맞는 `react-native-webview`가 추가되어 새 개발 빌드 또는 앱 업데이트가 필요합니다. 개발 서버는 `EXPO_PUBLIC_API_URL`로 지정합니다.

지도는 저장소의 Three.js 0.186.1을 사용하고 웹·앱은 1초마다 상태를 갱신합니다. 계산기는 기존 WebSocket을 사용합니다. 인터넷 또는 서버가 있는 로컬 네트워크가 필요하며 방은 24시간 후 만료됩니다. 참가자 토큰은 웹 localStorage / 앱 SecureStore에 저장합니다. 초대 링크와 보드 전용 WebView에는 참가자·계산기 조작 토큰이 포함되지 않습니다.

## 지도와 조작

플레이어 HUD는 상자 없이 스탠딩 옆에 테두리가 있는 닉네임, 승점 `◆◆◇`, 현재 체력 `♥4500`과 코인 `●5`, FP를 표시합니다. 작은 `1st`~`4th` 표시는 이번 라운드의 행동 순서입니다. 라운드가 끝날 때 현재 FP 내림차순, 동률이면 현재 체력 내림차순으로 다음 순서를 정하고 HUD가 새 자리로 이동합니다. 둘 다 같으면 이전 순서를 유지합니다. 거점과 좌석 번호는 바뀌지 않습니다. 이동 전에는 오른쪽 아래 큰 ‘이동’ 버튼을, 교전 선택 시에는 양쪽 스탠딩과 VS 및 ‘놓아주기 / 전투’ 버튼을 표시합니다. 선택 칸 정보는 클릭한 경우에만 오른쪽 위에 이미지와 함께 표시하며 닫을 수 있습니다.

외순환 40칸과 내순환 24칸을 팔각형으로 배치합니다. 외순환은 꼭짓점 사이에 4칸, 내순환은 2칸이 있으며 기존 외순환의 칸 간격을 유지합니다. 개인 거점은 연결로가 없던 네 꼭짓점으로 옮겼고, 기존 연결 지점 네 쌍은 도로 없이 교체 칸으로 연결됩니다. 내순환의 공용 거점 두 곳은 가까운 두 개인 거점에서 최단 거리 각각 7칸입니다(교체 이동을 1칸으로 세는 거리 기준). 기존 방은 자원과 남은 이동을 보존하여 새 지도 위치로 한 번만 전환합니다.

칸 배경 PNG를 웹·앱의 3D 보드, 2D 지도와 선택 칸 설명에 함께 사용합니다. 공용 거점 두 곳은 `party-icons/v2/camp-shared.png`를, 교체 칸 네 쌍은 외순환 시계 방향 순서로 버밀리언·마젠타·코발트·회청색 이미지를 사용합니다. 연결된 내·외순환 교체 칸에는 같은 색을 적용합니다. 개인 거점 네 곳은 1~4번 좌석에 맞는 배경에 주인의 캐릭터 아이콘을 시계 방향으로 45도 회전한 반투명 텍스처로 겹쳐 표시합니다. 3D에서는 발판 표면에 붙어 함께 원근 투영되며, 2D에서도 같은 회전과 투명도를 사용합니다. 플레이어 발밑의 그림자는 지면 높이에 고정된 24% 불투명도로 표시하여 대기 동작 중에도 칸 이미지를 가리지 않습니다. 플레이어는 `body_img` 스탠딩 이미지를 사용하며 로딩 실패 시 SD → 아이콘 → 기본 이미지 → 이름 첫 글자로 대체합니다. 도트 에셋은 아직 포함하지 않습니다.

기본 시점은 내 주변입니다. 드래그로 지도 위치를 옮기며 회전하지 않습니다. 모바일은 두 손가락으로 확대·축소하고, PC는 오른쪽 위 작은 − / + 버튼이나 휠을 사용합니다. 오른쪽 위 정사각형 지도 아이콘은 간소화한 2D 지도를 열며 3D를 표시할 수 없는 기기도 2D를 사용합니다. HUD나 지도 위 캐릭터 이미지를 누르면 해당 플레이어 위치로 카메라를 옮깁니다. 작은 화면에서는 플레이어 HUD도 작게 표시합니다. 칸을 클릭하거나 키보드로 선택을 실행하면 SELECTED PANEL에 종류와 효과를 표시합니다. 호버·단순 포커스·기본 툴팁은 설명을 열지 않습니다. 칸 번호·공개 메모·공개 리스트 편집은 표시하지 않습니다.

모든 도로는 양방향입니다. 시작 방향은 외곽 시계 방향이며 직전 칸으로 바로 되돌아가지 않습니다. 교체 후에도 진행 방향을 유지합니다. 이쪽으로 아이템을 사용하면 다음 이동 시작 방향을 선택합니다. 방향은 다음 턴·재접속·기절·부활 뒤에도 유지하며 ‘모두 제자리로’에서 초기화합니다.

도로의 상시 방향 화살표는 표시하지 않습니다. 주사위를 굴리면 남은 이동 횟수와 현재 진행 방향으로 지날 수 있는 모든 칸과 경로를 강조합니다. 강조된 칸을 클릭하면 그 칸으로 이어지는 경로 외의 강조가 옅어집니다. 이동 범위 밖의 칸을 선택하면 모든 이동 경로를 다시 강조합니다. 클릭은 미리보기와 설명만 바꾸며 실제 이동하지 않습니다. 질주의 다음 굴림이나 돌격 순간이동은 현재 굴림의 도로 미리보기에 포함하지 않습니다. 경로 미리보기는 중간에 교전·거점 선택이 있어도 계속 이동할 수 있는 경우를 포함합니다.

주사위는 화면 위에서 제자리에 고정된 채 75ms마다 눈이 바뀌다가 서버 결과로 고정되고, 잠시 뒤 테두리 숫자로 바뀝니다. 회전·이동 애니메이션은 없습니다. 두 개 굴림은 두 주사위를 함께 표시하고, 동시에 사라진 자리에 합계를 표시합니다. 이동력이 있으면 숫자 오른쪽 위에 작은 +N을 띄우고 숫자를 최종 이동 거리까지 올립니다. 숫자와 설명에는 배경 상자를 사용하지 않습니다. 연출 중에는 위치·칸 효과·아이템 사용을 잠시 멈추며, 3.2초가 지나면 숫자를 지우고 한 방향 구간을 자동으로 이동합니다. 갈림길에서는 지도 위 화살표를 누릅니다. 서버 시각과 결과를 함께 공유하여 다른 플레이어에게도 같은 결과를 표시하며, 재접속 시 지난 연출을 반복하거나 다시 굴리지 않습니다. 질주 추가 굴림도 매번 같은 연출을 사용합니다. 상점을 지나치면 바로 상점 선택 화면을 열며, 구매 또는 취소 후 남은 이동을 이어갑니다. 자기 거점을 지나칠 때 ‘멈추기 / 계속 이동’, 상대를 지나칠 때 ‘교전 / 계속 이동’을 선택합니다. 교전은 남은 이동 횟수를 보존합니다. 결과 확인 후 같은 만남에서 교전을 마친 상대는 후보에서 제외하고, 다른 상대나 거점·상점 선택이 없으면 남은 이동을 이어갑니다. 공격자가 KO되면 그 턴의 이동은 종료됩니다.

5초 동안 조작이 없을 때 새로운 행동을 수신하면 행동한 플레이어 위치를 따라봅니다. 최근에 지도나 버튼·아이템을 조작했다면 시점을 유지합니다. 내 턴이 시작되거나 내 캐릭터 이미지를 누르면 내 위치로 돌아옵니다. 반복적인 상태 조회만으로 시점을 바꾸지는 않습니다.

## 칸 효과

준비·재앙·횡재·질주·돌격·이벤트의 도착 효과는 남은 이동을 전부 사용해 정확히 멈춘 칸에서만 한 번 발동합니다. 통과·갈림길 선택·상대와 교전하기 위한 잠시 멈춤에는 발동하지 않습니다. 3D 화면의 체력·FP·코인 변화와 도착 안내도 실제 이동 애니메이션이 끝난 뒤 표시합니다. 통행 금지로 강제 정지하거나 자기 거점에서 멈추기로 선택하면 그 칸을 최종 도착으로 처리합니다.

| 칸 | 효과 |
| --- | --- |
| 거점 | 자기 거점은 지나칠 때 멈출 수 있습니다. 자기 거점 도착: 3코인과 무작위 아이템 1개. 모든 거점 도착: 코인이 충분하면 승점을 6 / 10 / 15코인에 자동 구매하고, 무작위 보상 아이템 3종 중 1개를 선택합니다. 턴당 한 번 구매합니다. 회복·교전 보호는 없습니다. |
| 질주 | 도착 연출과 남은 교전 선택이 끝나면 버튼 없이 주사위를 자동으로 한 번 더 굴려 이동하며 이동력도 더합니다. 다른 질주에 도착하면 다시 적용합니다. |
| 돌격 | 다른 플레이어 위치로 이동하거나 이동하지 않을 수 있습니다. 도착 칸 효과를 적용하며 그 상대에게 교전할 수 있습니다. 돌격 이동은 턴당 한 번입니다. |
| 상점 | 통과 중에도 잠시 열어 아이템 1개를 구매한 뒤 남은 이동을 계속합니다. 13종 중 무작위 3종을 제시하며, 모두 임시 가격 3코인. |
| 준비 | FP +(2 + 현재 공격자 보너스). 설명은 “도착 시, FP 획득”입니다. 기술 카드는 획득하지 않습니다. |
| 재앙 | 300 데미지. HP는 0 미만이 되지 않습니다. |
| 횡재 | 무작위 1~3코인을 얻습니다. 이동력·추가 주사위는 횡재에 적용하지 않습니다. |
| 이벤트 | 아래 여덟 가지 중 무작위 이벤트가 발생합니다. |
| 교체 | 정확히 도착하면 대응하는 다른 순환로의 교체 칸으로 이동하거나 현재 순환로에 남습니다. 이동 횟수를 새로 얻지 않습니다. 통과 시에는 발동하지 않습니다. |
| 공용 거점 | 누구나 통과 중 멈출 수 있고, 도착 시 승점을 구매합니다. 개인 거점의 3코인·아이템 보상은 없습니다. 교전 보호는 없습니다. |

추가 칸은 질주·돌격·재앙 위주로 구성합니다. 아이템 사거리는 양방향 최단 거리이며 교체 한 번을 거리 1로 포함합니다. 실제 이동 경로 미리보기에는 도로만 포함하고 교체 이후의 이동은 포함하지 않습니다.

이벤트에 도착하면 이동 연출 뒤 중앙에 해당 일러스트와 제목의 카드를 약 2.4초 동안 표시합니다. 카드가 끝나면 현재 턴의 참가자가 서버에 효과 적용을 요청하며 중복·조기 요청은 거절합니다. 효과를 실제 적용한 후 약 1.8초 동안 안내하고 숨깁니다. 이벤트 결과는 테이블 기록에 남으며 이전 이벤트 설명을 화면에 계속 표시하지 않습니다. 새로 접속한 참가자는 서버 시각 기준 남은 연출만 확인합니다. 수동으로 처리하는 패 말살도 로그에서 다시 확인할 수 있습니다.

아이템은 최대 3개, 자기 턴의 첫 이동 주사위를 굴리기 전에만 1개 사용할 수 있습니다. 이동 중·도착 후·질주 추가 이동 전에는 사용할 수 없으며 카드는 계속 열람할 수 있습니다. 거점 보상으로 가방이 넘치면 기존 아이템 교체 또는 새 아이템 받지 않기를 선택합니다. 아이템 상자는 빈 슬롯만 채웁니다. 승점 구매는 거점 **도착**에만 가능하며 통과나 시작 위치에 있는 것만으로는 구매하지 않습니다.

## 아이템

모두 임시 가격 **3코인**입니다. 제공된 v2 아이템 카드 13장과 이벤트 카드 8장을 `static/v2/party-cards/v2`에 원본 그대로 보관합니다. 그림과 이름·효과 문구를 이미지에 합성하지 않고, 게임 DB의 `PartyCard.effect_text`를 API로 가져와 이미지의 빈 설명란에 별도 표시합니다. 설명란 좌표는 원본 `card-data.json`의 `effectBox`를 사용합니다.

문구는 Django 관리자 → 루멘 파티 카드(`/admin/battlelog/partycard/`)에서 수정합니다. 종류·게임 키를 고정하여 같은 이름의 아이템/이벤트 ‘빨리 빨리’도 각각 관리합니다. 기존 방도 다음 상태 갱신부터 새 문구를 받습니다. 표시 문구를 수정해도 실제 회복량·사거리 등 게임 규칙은 바뀌지 않습니다. 상점에서는 큰 카드 이미지를 눌러 구매 대상을 선택하고 확인 버튼으로 구매하며, 내 가방의 카드는 내 턴이 아닐 때도 읽을 수 있습니다. 사용 가능할 때만 실제 아이템 사용 화면으로 이어집니다.

사거리는 양방향 최단 거리(교체 한 번은 1칸)이며 출발 칸은 0칸입니다. 대상·거리·사용 횟수는 서버에서도 확인합니다.

| 아이템 | 효과 |
| --- | --- |
| 붕대 | HP 200 회복, 최대 HP 상한. |
| 회복 키트 | HP 400 회복, 최대 HP 상한. |
| 전투 준비 | FP +4. |
| 빨리 빨리 | 다음 이동 주사위 2개. 중복 사용은 누적하지 않습니다. |
| 벽돌 투척 | 4칸 내 다른 캐릭터 하나에 500 데미지. |
| 조잡한 총 | 6칸 내 다른 캐릭터 하나에 300 데미지. |
| 이쪽으로 | 다음 이동의 첫 방향을 자유롭게 선택합니다. 첫 걸음 이후에는 선택한 방향을 유지합니다. |

## 라운드와 FP

라운드 제한은 없습니다. 턴 시작 코인 +1 → 주사위 + 이동력 → 이동·칸 효과·선택적 교전 → 턴 종료 순입니다.

- 이동력: `floor((round - 1) / 3)`. 4·7·10라운드부터 +1·+2·+3입니다.
- 공격자 보너스: `floor((round - 1) / 5)`. 6·11·16라운드부터 +1·+2·+3FP입니다.
- 이동 거리: 주사위 눈의 합 + 이동력. ‘빨리 빨리’는 두 주사위의 합을 사용합니다.
- 준비·아이템·이벤트 FP는 누적되고 음수도 저장합니다. 턴 종료로 사라지지 않으며 다음 교전 시작 FP에 사용합니다. 공격자는 공격자 보너스를 더합니다. 교전 후 FP는 이어지지 않습니다. 취소하면 원래 누적 FP를 복원하며 공격자 보너스는 누적시키지 않습니다.
- 승점 3점를 모은 라운드가 끝나면 승점 → 남은 코인 순으로 우승을 판정하며 동률은 공동 우승입니다.

## 코인과 보급함

새 참가자의 초기 보유 코인은 0입니다. 기존 턴 시작 수입 1코인은 유지하므로 첫 행동 플레이어는 턴이 시작되면 1코인을 받습니다. 기존 방에 저장된 코인은 초기화하지 않습니다. 배포 시 `0033_partyplayer_initial_coins_zero` 마이그레이션을 적용합니다.

교전에서는 양쪽 플레이어가 상대에게 준 실제 피해 합계 500당 2코인을 받습니다. 두 공방의 피해를 합친 뒤 500 미만은 버리며, 나머지를 다음 교전으로 넘기지 않습니다. HP 회복 전의 유효 피해도 포함하고, 되돌린 입력·0 미만의 과잉 피해·최대 HP를 넘긴 부분의 피해는 제외합니다. 보상은 참가자 한 명이 결과를 반영할 때 한 번 지급하고 로그에 남깁니다. 취소한 교전에는 보상이 없습니다. 아이템·재앙·식중독과 보급함 피해에는 이 보상이 없습니다. 플레이어를 기절시키면 기존 승점 1점에 5코인을 추가 지급합니다. 아이템으로 기절시켜도 처치 보상은 지급하며, 환경 피해에는 처치 보상이 없습니다.

3·6·9…라운드가 모두 끝나면(4·7·10…라운드 시작) 무작위 빈 칸에 HP 800 보급함 3개가 생성됩니다. 기존 보급함은 남고 현재 플레이어 위치와 다른 보급함 위치를 피해 생성합니다. 빈 칸이 3개 미만이면 가능한 수만큼 생성합니다. 위치와 HP는 3D·2D 지도와 모든 참가자·관전자에게 공개됩니다.

보급함과 같은 칸에 도착하거나 통과하면 잠시 멈추고 공격하거나 지나갈 수 있습니다. 통과 중 원래 칸의 도착 효과는 발생하지 않습니다. 실물 기술 카드를 속도 수치가 엄격히 증가하는 순서로 사용하고, 속도 목록과 콤보 보정·카드 효과를 적용한 최종 피해를 입력합니다. 속도는 연속된 수일 필요가 없고 카드 장수 제한은 없습니다. 카드 선택·콤보 판정·리스트 처리는 실물 테이블에서 진행하며, 보급함 입력창은 카드 속도 순서와 최종 피해를 반영합니다. 한 번 만날 때 하나의 콤보를 사용하며, 같은 턴에도 이동해 다시 만나면 새로 공격할 수 있습니다. 남은 HP는 유지되고 누구나 이후에 마무리할 수 있습니다. 파괴한 플레이어에게만 2코인을 주며 교전 피해 보상·기절 승점·처치 보상은 추가 지급하지 않습니다. 공격·지나가기 후 다른 선택이 없으면 남은 이동이나 자동 턴 종료를 이어갑니다.

## 최대 두 번의 공방과 결과 제출

거점을 포함한 모든 칸에서 교전할 수 있습니다. 기절하거나 투명 망토 효과 중인 상대는 선택할 수 없습니다. 같은 칸 도착 또는 통과 시 도전하며 교전은 선택 사항입니다. 같은 만남에서 각 상대에게 한 번씩 교전할 수 있습니다. 완료한 상대는 서버에 기록하여 재접속·앱 전환·직접 요청으로도 즉시 다시 교전할 수 없습니다. 이동해 새로운 칸에 들어가거나 한 바퀴 돌아 다시 만난 경우, 다음 자기 턴에는 다시 도전할 수 있습니다. 취소한 교전은 기회를 소모하지 않으며, 반격 아이템의 교전은 별도로 허용합니다. 같은 칸에 정확히 도착한 경우에도 교전할 수 있습니다. 공격자 보너스는 각 교전 시작마다 적용하며 HP는 직전 교전 결과를 이어받습니다. 참가자 현재 HP와 누적 FP·공격자 보너스로 기존 계산기를 만들고 최대 두 번의 공방을 진행합니다. 첫 번째 공방 완료 시 어느 한쪽이라도 HP가 0이면 두 번째 공방 없이 전투를 종료합니다. HP를 입력하는 중에는 수정할 수 있으며, 공방 완료를 누를 때 종료 여부를 확정합니다. 종료된 계산기는 조작이 잠기고 파티로 돌아갑니다. 참가자 한 명이 '전투 결과 반영'을 누르면 HP·패시브·기절 결과를 즉시 한 번 반영합니다. 승자·무승부 선택과 교전 승패 기록은 없습니다. 다른 참가자의 확인은 필요하지 않으며 중복 제출로 기절 승점을 다시 받을 수 없습니다. 이전 클라이언트의 winner 입력은 무시합니다. 방장은 교전을 취소할 수 있습니다.

계산기에는 파티 복귀 버튼이 있습니다. 교전 승패는 기록하지 않고 코인 약탈은 없습니다. 교전 피해 500당 2코인, 플레이어 기절 시 승점 1점과 5코인을 얻습니다. 환경 피해에는 승점이 없습니다. 계산기의 기절은 참가자 한 명의 결과 제출 후 한 번 반영됩니다. 기절한 플레이어는 다음 자기 턴에 행동하지 않고 쉬며, 그다음 자기 턴에 쓰러진 자리에서 부활합니다. 부활 체력은 최대 HP의 절반을 100 단위로 올림합니다(4,450 → 2,300, 최대 HP 상한). 손패를 전부 버리고 부활 시점 HP에 따른 최대 손패까지 획득한 뒤 완료 버튼을 누릅니다. 패시브는 초기 상태로 돌아가며, 평소 교전 사이에는 패시브 상태를 이어갑니다. 식중독은 쉬는 턴에도 기간이 줄고 부활 턴에도 적용합니다. 패·리스트·브레이크 존·콤보·캐치와 무작위 카드 버리기는 실물 테이블에서 관리합니다.

## 테스트와 일관성

`LumenGG.test_settings` 또는 `LUMENGG_DEBUG=1`과 `LUMENGG_PARTY_TEST_CONTROLS=1`을 함께 설정한 서버는 ‘테스트 · 플레이어 전환’으로 실제 참가자·관전 시점을 선택합니다. 운영 환경에서는 UI와 전환 API가 비활성화됩니다. 전환은 턴·위치·버전을 바꾸지 않으며 자기 턴 권한을 유지합니다.

방 행동은 트랜잭션·행 잠금·`expected_version`으로 중복 이동과 동시 조작을 거절합니다. 자동 이동도 갈림길·자기 거점·상대 통과에서 멈춥니다. 공방은 계산기 행 잠금·`expected_exchange`로 보호하며 결과 제출은 방 행 잠금·계산기 버전 검증으로 한 번만 반영합니다. 기존 두 공방 완료 기록과 결과 확인 대기 중인 교전도 참가자 한 명이 제출해 마칠 수 있습니다. 일반 계산기와 대회 계산기의 동작은 유지합니다.


### 자동 턴 종료와 도착 선택

남은 이동과 처리할 선택이 모두 없으면 이동·이벤트 연출 뒤 자동으로 턴을 종료합니다. 교전·돌격·교체·승점 구매 보상 선택·거점 보상 교체·손패 교체가 남으면 기다리며, 기절로 쉬는 턴도 자동 종료합니다. 자동 종료 요청은 서버가 조건과 현재 턴을 다시 확인하고 방 버전으로 중복 실행을 막습니다.

상점과 돌격은 화면 중앙에서 큰 아이템 카드 또는 상대 스탠딩을 보고 선택한 뒤, 아래 확인 버튼으로 실행하거나 취소합니다. 초기 선택은 없으며 선택 없이 확인할 수 없습니다. 상점 상품은 중복 없는 무작위 3종으로 턴 동안 고정하고 재접속·관전·앱 전환에도 유지합니다. 제시되지 않은 상품은 서버에서도 구매할 수 없습니다. 구매·취소 뒤 통과 중이라면 남은 이동을 이어가고, 정확히 도착했다면 다른 선택이 없을 때 턴을 종료합니다.


자기 거점이나 공용 거점을 통과할 때 중앙에 ‘이대로 이동 / 거점에 멈추기(승점 구매까지 앞으로 N골드)’를 표시합니다. 부족 금액은 자기 거점의 도착 보상 3코인까지 반영합니다. 승점 구매 보상은 기존 자기 거점의 무작위 아이템과 별도이며, 기존 보상 교체를 마친 뒤 3종 중 하나를 선택합니다. 가방이 가득 차면 다시 교체할 아이템을 고르므로 보상이 덮어쓰이지 않습니다. 교체 칸은 중앙에 ‘반대편 교체로 이동 / 여기에 멈추기’를 표시합니다.

보유 아이템은 이름을 별도로 반복하지 않고 큰 카드 자체로 표시하며 아래 경계 밖으로 2/3를 숨깁니다. PC는 호버, 모바일은 탭으로 펼칩니다. 카드를 중앙 영역에 끌어 놓으면 자기 대상 아이템은 즉시 사용하고, 캐릭터·지점·숫자 선택이 필요한 아이템은 대상을 정한 뒤 사용합니다. 영역 밖 드롭·취소·이동 후 드롭은 아이템을 소모하지 않습니다. 키보드나 두 번째 탭으로 기존 카드 보기·사용 선택 화면도 열 수 있습니다.

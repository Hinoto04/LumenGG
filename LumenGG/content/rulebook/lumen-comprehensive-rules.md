- 처음 게임을 배우는 플레이어는 [처음 플레이 가이드](./lumen-beginner-guide.md)를 먼저 읽는 것을 권장합니다.

- `[확인 필요]`는 제작진이 한 번 더 확정해야 하는 항목입니다.
- 원본 페이지의 시각 자료와 웹 활용 방식은 [시각 자료 인덱스](./VISUAL_ASSET_INDEX.md)에서 확인할 수 있습니다.

# 0. 규칙서를 읽기 전 알아야 할 내용

이 장은 게임의 개요와 이 문서의 지위, 규칙 간 우선순위와 읽기 전 주의사항을 설명합니다.

## 0.1 게임 개요

<a id="rule-0-1-1"></a>
**0.1.1** 루멘콘덴서는 공격 기술로 상대 체력을 줄이고 수비 기술로 상대 공격을 막는 대전형 카드 게임이다.

## 0.2 문서의 지위와 우선순위

<a id="rule-0-2-1"></a>
**0.2.1** 이 문서는 기존 마스터 룰북과 공식 결정 답변을 통합한 검토 초안이다. 정식 발행 전까지 카드별 최신 공식 판정과 제작진 공지를 함께 확인한다. `[검토 초안]`

<a id="rule-0-2-2"></a>
**0.2.2** 문서 간 우선순위와 한국어·영어·일본어판의 기준 언어는 아직 공식 확정되지 않았다. 이 초안에서는 편집 편의를 위해 다음 순서로 해석한다. `[확인 필요]`

1. 최신 정오표 및 공식 카드 판정
2. 카드 텍스트
3. 종합 규칙
4. 입문 가이드
5. 예시

> [!WARNING]
> 위 순서는 공식 답변으로 확정된 규칙이 아니라, 문서 편집을 위한 임시 우선순위입니다. 정식 발행 전에 예시의 법적 지위와 번역본 충돌 시 기준 언어를 확정해야 합니다.

<a id="rule-rule-contracts"></a>
## 0.3 규칙 객체와 참조 계약

<a id="rule-contract-unit"></a>
**0.3.1** 각 규칙은 하나의 독립된 **규칙 객체**다. 규칙 객체는 참조 키, 상위 규칙, 규범 본문과 참조 규칙을 가진다. 규범 본문은 적용 대상, 전제조건, 수행할 처리, 처리 결과와 예외 중 해당하는 항목을 명시하며, 명시하지 않은 조건·결과·예외를 임의로 보충하지 않는다.

<a id="rule-reference-key"></a>
**0.3.2** **참조 키**는 규칙 객체를 식별하는 유일하고 지속적인 문자열이다. 참조 키는 `rule-...` 형식을 사용하며 같은 키를 둘 이상의 규칙에 부여할 수 없다. 표시 번호나 배치가 바뀌어도 참조 키의 의미는 바뀌지 않으며, 변경 전 키는 같은 규칙의 별칭으로 보존한다.

<a id="rule-scope-inheritance"></a>
**0.3.3** 하위 규칙은 상위 규칙이 정한 정의와 적용 범위를 상속한다. 하위 규칙이 상위 규칙의 일부를 명시적으로 제한하거나 예외로 선언하면 그 범위에서 하위 규칙을 우선하고, 명시적으로 변경하지 않은 부분은 상위 규칙과 함께 적용한다. 한 규칙의 하위 규칙은 다른 형제 규칙의 범위를 자동으로 변경하지 않는다.

<a id="rule-dependency-resolution"></a>
**0.3.4** 규칙 객체가 다른 규칙을 참조하면 참조된 규칙의 정의·조건·절차를 다시 적지 않고 그대로 사용한다. 절차 처리 중 다른 절차를 참조하면 참조된 절차를 완료한 뒤 호출한 규칙의 다음 처리로 돌아간다. 단순한 상호 참조는 처리의 반복을 발생시키지 않으며, 반복은 규칙이 재실행 조건과 종료 조건을 명시한 경우에만 수행한다.

<a id="rule-normative-clause-contract"></a>
**0.3.5** 조건부 규칙은 조건이 참일 때만 지시된 처리를 수행한다. “한다”는 의무 처리이고 “할 수 있다”는 선택 처리이며, 처리 결과는 해당 문장이 정한 범위에서만 게임 상태를 변경한다. 예외는 적용 대상과 대체할 처리를 명시해야 하며, 예외가 끝난 뒤에는 변경되지 않은 일반 규칙을 계속 적용한다.

<a id="chapter-1"></a>
# 1. 게임 내 객체의 정의

**게임 객체**란 규칙이나 카드 효과가 대상으로 지정할 수 있는 것을 말합니다. 게임 객체는 **플레이어**와 **카드** 두 종류입니다. 덱은 게임 준비에 사용하는 카드 구성이며, 존과 FP 영역은 게임 영역이므로 그 자체는 게임 객체가 아닙니다.

## 1.1 플레이어

<a id="rule-3-2-1"></a>
**1.1.1** 플레이어는 게임에 참여하여 규칙과 카드 효과의 대상을 될 수 있는 게임 객체다. 한 게임에는 두 플레이어가 있으며, 각 플레이어는 자신과 자신이 아닌 상대 플레이어로 구분된다.

<a id="rule-3-2-2"></a>
**1.1.2** 플레이어 객체는 다음 정보를 가진다. 규칙이나 카드 효과가 이 정보의 일부를 확인하거나 변경할 수 있다.

| 정보 | 설명 |
|---|---|
| 자신·상대 구분 | 효과를 발생시킨 카드의 소유자를 자신, 다른 플레이어를 상대로 구분한다. |
| 현재 체력 | 캐릭터 카드에 표시하는 현재 잔존 체력이다. |
| 현재 FP | FP 영역에 표시하는 양수·0·음수의 공개 수치다. |
| 패 매수 | 현재 패에 있는 카드 수이며 공개 정보다. |
| 패 매수 상한 | 캐릭터 카드의 현재 체력 구간에 표시된 패의 최대 매수다. 체력이 바뀌면 처리 단위 종료 후 다시 계산한다. |
| 우선권 | 동시에 처리할 행동이나 효과의 처리 순서를 정하는 보유 여부다. |
| 캐릭터 마크 | 자신의 캐릭터 카드에 표시된 마크이며 덱 구성과 일부 효과가 참조한다. |
| 연결 영역 | 자신의 패와 각 존처럼 그 플레이어에게 연결된 게임 영역이다. |

<a id="rule-3-2-3"></a>
**1.1.3** 처리 단위 종료 후 플레이어의 패가 현재 패 매수 상한을 초과하면, 그 플레이어는 상한을 초과한 만큼 즉시 버린다. 이 처리는 다음 효과를 처리하기 전에 수행한다.

<a id="rule-3-2-4"></a>
**1.1.4** 카드 텍스트가 “자신”을 지정하면 그 효과를 발생시킨 카드의 소유자인 플레이어 객체를, “상대”를 지정하면 다른 플레이어 객체를 뜻한다. 카드 효과가 플레이어를 대상으로 지정하면 카드나 존이 아니라 해당 플레이어 객체를 대상으로 한다.

> [!EXAMPLE]
> 효과 처리 중 여러 장을 패에 넣어 상한을 넘더라도 그 효과를 끝까지 처리합니다. 효과가 끝난 직후 현재 체력 구간의 패 상한을 확인하고 초과분을 버립니다.

## 1.2 카드

<a id="rule-game-object-card"></a>
**1.2.1** 카드는 게임에 사용하는 인쇄물로서 규칙과 카드 효과의 대상이 될 수 있는 게임 객체다. 카드 객체는 존을 이동하거나 앞·뒷면 상태가 바뀌어도 같은 객체로 취급한다.

<a id="rule-card-common-information"></a>
**1.2.2** 카드 객체는 다음 공통 정보를 가지며, 카드 종류에 따라 일부 정보가 없을 수 있다.

| 정보 | 설명 |
|---|---|
| 소유자 | 그 카드를 자신의 덱에 넣고 게임을 시작한 플레이어다. 카드가 다른 존으로 이동해도 소유자는 바뀌지 않으며, 별도 지시가 있을 때만 변경된다. |
| 카드 명칭 | 카드의 이름이며 동명 카드 판정과 카드 효과의 참조에 사용한다. |
| 카드 종류·분류 | 캐릭터, 특성, 공격·수비·특수 기술과 얼티밋 여부 등 카드가 속한 분류다. |
| 캐릭터 마크 | 덱 구성 가능 여부와 카드 효과가 참조하는 마크다. 중립 기술은 중립 마크를 가진다. |
| 기능·효과 | 카드가 항상 적용하는 기능과 정해진 시점에 처리하는 효과다. |
| 수치·판정 정보 | 체력, 패 상한, 속도, 데미지, FP, 위치, 특수 판정처럼 카드 종류에 따라 사용하는 정보다. |
| 표시 상태·현재 존 | 카드가 앞면인지 뒷면인지와 현재 놓인 존이다. 공개 범위와 사용할 수 있는 규칙을 정할 때 참조한다. |
| 수록 식별 정보 | 카드 넘버, 일러스트, 수록판처럼 카드를 정리하고 판본을 식별하는 정보다. |

<a id="rule-card-character-information"></a>
**1.2.3** 캐릭터 카드는 플레이어를 대변하는 카드다. 캐릭터 정보로 소속·이명·이름 등을, 게임 정보로 체력 구간별 체력과 패 매수 상한, 캐릭터 마크를 가지며 카드 넘버를 수록 식별 정보로 가진다. 게임 중 플레이어의 현재 체력과 패 매수 상한은 이 카드에 표시한다.

<a id="rule-3-3-1"></a>
**1.2.4** 특성 카드는 캐릭터 고유의 기능과 효과를 가진 카드다. 카드 명칭, 특성 분류, 기능·효과, 캐릭터 마크를 가지며 게임 준비 시 캐릭터 카드 옆의 특성 존에 놓는다.

<a id="rule-3-3-2"></a>
**1.2.5** 특성 카드의 기능과 효과는 게임 시작 직후부터 적용한다.

<a id="rule-3-4-1"></a>
**1.2.6** 공격 기술 카드는 배틀 존에 사용하여 상대에게 데미지를 줄 수 있는 기술 카드다. 카드 명칭, 공격 위치, 속도, 손·발 판정, 판정 결과별 FP, 특수 판정, 기능·효과, 캐릭터 마크, 데미지와 플레이버 텍스트를 정보로 가질 수 있다.

<a id="rule-3-4-2"></a>
**1.2.7** 수비 기술 카드는 배틀 존에 사용하여 상대 공격을 방어하거나 회피하는 기술 카드다. 카드 명칭, 방어하거나 회피할 위치, 특수 판정, 기능·효과, 캐릭터 마크와 플레이버 텍스트를 정보로 가질 수 있다.

<a id="rule-11-1-1"></a>
**1.2.8** 특수 기술 카드는 기재된 사용 조건을 만족했을 때 효과를 처리하는 기술 카드다. 카드 명칭, 특수 기술 분류, 사용 조건, 기능·효과, 캐릭터 마크와 배치할 존 등의 정보를 가질 수 있다. 사용할 때에는 조건 확인, 카드 공개, 지정된 존 배치, 효과 처리 순서로 진행하며, 조건을 충족하지 못하면 공개하거나 배치할 수 없다.

<a id="rule-11-1-2"></a>
**1.2.9** 특수 기술 카드는 사이드 덱, 루멘 존, 얼티밋 존, 브레이크 존에만 존재할 수 있으며 패에 넣을 수 없다.

<a id="rule-11-2-1"></a>
**1.2.10** 얼티밋은 공격·수비·특수 기술 카드가 추가로 가질 수 있는 분류다. 얼티밋 기술 카드는 기본 카드 종류의 정보에 더해 얼티밋 여부를 가지며, 덱에 0장 또는 1장 채용하고 게임 시작 시 얼티밋 존에 앞면으로 공개한다. 프로텍터는 다른 기술 카드와 같은 것을 사용한다.

<a id="rule-11-2-2"></a>
**1.2.11** 얼티밋 공격·수비 기술은 패에 넣은 뒤 일반 공격·수비 기술과 같은 규칙으로 처리한다. 사용 후에도 패·리스트·브레이크 존 등 실제 이동 결과가 유지되며 얼티밋 존으로 자동으로 돌아가지 않는다.

<a id="rule-11-2-3"></a>
**1.2.12** 얼티밋 특수 기술은 조건을 만족했을 때 카드에 기재된 절차로 루멘 존 등에 배치하며 패에 넣을 수 없다.

<a id="rule-11-2-4"></a>
**1.2.13** 얼티밋 공격·수비 기술이 리스트로 보내지면 일반 공격·수비 기술과 동일하게 리스트에 남는다.

<a id="rule-11-2-5"></a>
**1.2.14** 얼티밋 특수 기술이 사이드 덱으로 보내지면 사이드 덱에 놓는다.

## 2.1 존의 정의

<a id="rule-game-area-common-rules"></a>
**2.1.1** 캐릭터 존, 특성 존, 패, 리스트, 사이드 덱, 배틀 존, 루멘 존, 얼티밋 존과 브레이크 존은 각 플레이어와 하나씩 연결되어 있으므로 게임 중 각 종류가 2곳 존재한다. 각 플레이어에게 연결된 영역을 그 플레이어의 영역이라 한다. 카드 효과나 규칙이 별도로 정하지 않으면, 카드는 이동하려는 존의 허용 카드, 표시 상태, 공개 범위와 매수 제한을 따른다.

<a id="rule-2-1-4"></a>
**2.1.2** 캐릭터 존은 플레이어를 대변하고 잔존 체력을 표시하는 캐릭터 카드를 두는 곳이다. 캐릭터 존은 각 플레이어에게 하나씩 연결되어 있으며, 각 플레이어는 게임 준비 시 자신의 캐릭터 카드 1장을 앞면으로 놓는다. 캐릭터 카드의 정보와 현재 체력 표시는 공개 정보이며 모든 플레이어가 확인할 수 있다. 일반적인 덱에는 캐릭터 카드가 1장만 들어가므로, 카드 효과나 규칙이 달리 정하지 않는 한 캐릭터 존에는 그 카드 1장만 놓인다.

<a id="rule-2-1-5"></a>
**2.1.3** 특성 존은 캐릭터의 고유 기능과 효과를 가진 특성 카드를 두는 곳이다. 특성 존은 각 플레이어에게 하나씩 연결되어 있으며, 각 플레이어는 게임 준비 시 자신의 특성 카드 1장을 캐릭터 카드 옆에 앞면으로 놓는다. 특성 카드의 정보는 공개되어 모든 플레이어가 확인할 수 있고, 그 기능과 효과는 게임 시작 직후부터 적용된다. 카드 효과나 규칙이 달리 정하지 않는 한 특성 존에는 그 카드 1장만 놓이며 카드의 순서는 의미가 없다.

<a id="rule-1-2-1"></a>
**2.1.4** 패는 플레이어가 레디하거나 카드 효과로 사용할 수 있는 기술 카드를 보유하는 비공개 존이다. 패는 각 플레이어에게 하나씩 연결되어 있으며, 공격·수비 기술과 패에 넣을 수 있는 얼티밋 공격·수비 기술을 둘 수 있지만 특수 기술은 둘 수 없다. 소유자는 자신의 패 내용 전체를 확인할 수 있고 카드 순서는 규칙상 의미가 없지만, 상대는 게임 중 그 내용을 확인할 수 없다. 다만 게임 준비 시 초기 패를 서로 확인한 뒤 소유자에게 돌려주며, 게임 시작 후에는 다시 비공개로 취급한다. 패의 매수는 공개 정보이고 최대 매수는 캐릭터 카드의 현재 체력 구간에 표시된 [[rule-3-2-2|패 매수 상한]]을 따르며, 하나의 처리 단위가 끝난 뒤 상한을 넘으면 [[rule-3-2-3|초과분을 즉시 버린다]].

<a id="rule-2-1-1"></a>
**2.1.5** 리스트는 각 플레이어가 레디 페이즈에 사용하지 않는 공개된 기술을 모아 두는 존이다. 리스트는 각 플레이어에게 하나씩 연결되어 있으므로 게임 중 2곳 존재한다. 리스트의 최대 매수는 14장이며, 리스트의 카드 매수는 이 상한을 넘을 수 없다. 리스트가 14장인 상태에서 카드가 리스트로 이동하려 하면 그 카드는 리스트로 이동하는 대신 [[rule-10-2-1|브레이크]]된다. 초기 리스트는 게임 준비가 끝날 때까지 뒷면 비공개 상태로 두고 양쪽 플레이어가 준비를 마친 뒤 동시에 앞면으로 공개하며, 게임 시작 후에는 앞면 공개 상태를 유지한다. 리스트의 앞면 카드 정보와 카드 매수는 모든 플레이어가 확인할 수 있고, 카드의 순서는 규칙상 의미가 없다.

<a id="rule-2-1-2"></a>
**2.1.6** 사이드 덱은 초기 패와 초기 리스트에 넣지 않은 기술 카드와 특수 기술 카드를 두는 뒷면 존이다. 사이드 덱은 각 플레이어에게 하나씩 연결되어 있으므로 게임 중 2곳 존재한다. 일반적인 20장 기술 카드 구성에서는 초기 패 5장과 초기 리스트 9장을 제외한 6장으로 게임을 시작하지만, 덱 구성이나 준비를 바꾸는 효과가 있으면 그 효과를 따른다. 사이드 덱의 카드 매수는 공개 정보지만 내용과 순서는 상대에게 비공개이며, 소유자는 게임 시작 전에 순서를 정하고 게임 중 자신의 사이드 덱 내용과 순서를 확인할 수 있다. 게임 중 고정된 최대 매수는 없으며 카드 효과와 존 이동에 따라 매수가 바뀔 수 있다.

<a id="rule-2-1-6"></a>
**2.1.7** 배틀 존은 레디 페이즈에 패에서 선택한 기술 카드 1장을 놓고 레디를 선언하는 존이다. 배틀 존은 각 플레이어에게 하나씩 연결되어 있으므로 게임 중 2곳 존재하며, 각 플레이어의 일반적인 레디 카드 수용량은 1장이다. 레디한 카드는 배틀 페이즈가 시작될 때까지 뒷면으로 두므로 상대는 그 내용을 확인할 수 없고, 레디 선언 후에는 카드를 바꾸거나 선언을 취소할 수 없다. 배틀 페이즈에는 양쪽 레디 카드를 동시에 앞면으로 공개하며, 공개된 카드의 정보는 모든 플레이어가 확인할 수 있다. 배틀 종료 시 레디 카드는 기본적으로 패로 돌아가지만 콤보, 캐치, 브레이크 등 별도 이동 규칙이 있으면 그 규칙을 따른다.

<a id="rule-2-1-7"></a>
**2.1.8** 루멘 존은 카드 효과가 “루멘 존에 배치한다”고 지정한 카드를 두는 존이다. 루멘 존은 각 플레이어에게 하나씩 연결되어 있으므로 게임 중 2곳 존재하며, 주로 사용 절차를 마친 특수 기술이 놓이지만 실제로 놓을 수 있는 카드와 이동 시점은 해당 효과를 따른다. 카드의 체류 기간, 이동 방법, 매수와 순서는 그 카드를 배치한 효과가 정하며 고정된 최대 매수는 없다. 효과가 앞·뒷면이나 공개 범위를 정하면 그 지시를 따르고, 명시가 없으면 이 검토 초안에서는 앞면 공개 상태로 놓아 모든 플레이어가 정보를 확인할 수 있는 것으로 처리한다. `[확인 필요]`

<a id="rule-2-1-9"></a>
**2.1.9** 얼티밋 존은 덱에 채용한 얼티밋 기술 카드를 두는 존이다. 얼티밋 존은 각 플레이어에게 하나씩 연결되어 있으므로 게임 중 2곳 존재하지만, 얼티밋 기술을 채용하지 않은 플레이어의 얼티밋 존은 비어 있다. 플레이어는 게임 준비 시 채용한 얼티밋 기술 0장 또는 1장을 앞면으로 놓고, 앞면인 동안 그 카드 정보는 모든 플레이어가 확인할 수 있다. 카드 효과가 명시하면 뒷면이 될 수 있으며 그때의 공개 범위는 해당 효과를 따른다. 얼티밋 공격·수비 기술이 이 존을 떠난 뒤에는 일반 기술과 같은 이동 규칙을 적용하고 얼티밋 존으로 자동 복귀하지 않으며, 얼티밋 특수 기술은 패에 넣을 수 없다.

<a id="rule-2-1-3"></a>
**2.1.10** 브레이크 존은 규칙이나 카드 효과로 브레이크된 카드를 두는 공개 존이다. 브레이크 존은 각 플레이어에게 하나씩 연결되어 있으므로 게임 중 2곳 존재한다. 브레이크된 카드는 앞면으로 놓고 그 정보와 매수는 모든 플레이어가 확인할 수 있으며, 카드의 순서는 규칙상 의미가 없고 고정된 최대 매수도 없다. 브레이크 존의 카드는 일반적으로 그 게임에서 다시 사용할 수 없지만, 카드 효과나 규칙이 별도 이동을 지시하면 그 지시를 따른다. 패·리스트·루멘 존·배틀 존에서 공격 또는 수비 기술이 브레이크되면 [[rule-10-2-1|브레이크 보충 규칙]]을 적용하고, 특수 기술에는 그 보충을 적용하지 않는다.

<a id="rule-2-1-8"></a>
**2.1.11** FP 영역은 카드를 두는 존이 아니라 각 플레이어의 현재 FP 수치를 구분하여 표시하는 게임 영역이다. 각 플레이어는 서로 독립된 FP 수치 하나를 가지며, 양쪽 FP는 모두 공개 정보로서 모든 플레이어가 확인할 수 있다. FP는 양수, 0 또는 음수가 될 수 있고 정해진 상한과 하한은 없으며, 카드 매수나 카드 순서에 관한 규칙은 적용하지 않는다. FP는 우선권 결정과 공격 속도 계산 등에 사용하며, 배틀에서는 양쪽이 보유한 FP 전부를 적용한 뒤 0으로 만든다.

## 2.2 존별 공개 정보

<a id="rule-2-2-1"></a>
**2.2.1** 각 존의 카드 매수와 양쪽 플레이어의 현재 체력·FP는 우선권 비교와 합법성 확인에 필요한 공개 정보다. 공개 존의 앞면 카드에 적힌 정보는 모든 플레이어가 확인할 수 있다. 패와 뒷면 카드처럼 비공개로 정한 정보는 소유자 또는 해당 존의 규정이 허용한 플레이어만 확인할 수 있으며, 게임 준비 중 서로 확인하는 초기 패는 예외로 한다. 상대의 공개 카드를 손으로 들어 확인해야 할 때에는 먼저 허가를 받고 확인한 뒤 원래 위치와 순서를 유지해야 한다.

# 3. 게임 준비

## 3.1 덱 구성 규칙

<a id="rule-3-1-1"></a>
**3.1.1** 덱은 게임 준비에 사용하는 카드 묶음이며 게임 객체가 아니다. 스타터 덱은 개봉 즉시 사용할 수 있고, 직접 구축한 덱은 이 절의 덱 구성 제한을 지켜야 한다.

<a id="rule-3-5-1"></a>
**3.1.2** 기본 덱은 총 22장 또는 23장으로 구성하며, 카드 구성은 다음과 같다. 캐릭터의 특성이 덱 구성 매수를 변경하면 그 카드 텍스트를 따른다.

- 캐릭터 카드 1장
- 특성 카드 1장
- 공격·수비·특수 기술 카드 합계 20장
- 얼티밋 카드 0장 또는 1장

<a id="rule-3-5-2"></a>
**3.1.3** 캐릭터 특성이 덱 구성 제한을 변경하는 경우, 카드 텍스트가 명시한 항목만 변경한다. 명시되지 않은 덱 매수·카드 종류·마크·동명 제한은 그대로 적용한다.

<a id="rule-3-5-3"></a>
**3.1.4** 기본적으로 이름이 같은 카드는 한 덱에 2장 이상 넣을 수 없다. 카드 번호, 일러스트, 수록판이 달라도 카드 명칭이 같으면 동명 카드로 본다.

<a id="rule-3-5-4"></a>
**3.1.5** 덱의 기술 카드는 중립 마크이거나 자신의 캐릭터 마크와 같아야 한다.

<a id="rule-3-5-5"></a>
**3.1.6** 덱의 기술 카드 중 최소 10장은 자신의 캐릭터 마크와 같아야 한다.

<a id="rule-3-5-6"></a>
**3.1.7** 특성 카드의 캐릭터 마크는 자신의 캐릭터 카드 마크와 같아야 한다.

## 3.2 게임 준비 절차

<a id="rule-4-1-1"></a>
**3.2.1** 게임 시작 전에 각 플레이어는 캐릭터 카드, 특성 카드, 선택한 얼티밋 카드를 앞면으로 놓는다.

<a id="rule-4-1-2"></a>
**3.2.2** 게임 시작 시 주사위, 가위바위보, 코인 토스 등 합의한 방법으로 최초 우선권 보유자를 결정한다.

<a id="rule-4-1-3"></a>
**3.2.3** 각 플레이어는 특수 기술이 아닌 기술 카드 5장을 초기 패로, 9장을 초기 리스트로 선택한다. 따라서 합법적인 덱은 특수 기술이 아닌 기술 카드를 최소 14장 포함해야 한다.

<a id="rule-4-1-4"></a>
**3.2.4** 초기 패와 리스트로 선택하지 않은 기술 카드와 특수 기술 카드는 사이드 덱에 뒷면으로 놓는다.

<a id="rule-4-1-5"></a>
**3.2.5** 초기 리스트 9장을 먼저 뒷면으로 놓고 양쪽이 준비를 마친 뒤 앞면으로 공개한다.

<a id="rule-4-1-6"></a>
**3.2.6** 양쪽 플레이어는 초기 패 5장을 서로 교환하여 확인한 뒤 주인에게 돌려준다.

<a id="chapter-4"></a>
# 4. 게임 진행

한 턴은 **루멘 → 레디 → 배틀 → 겟 → 리커버리**의 다섯 페이즈로 진행됩니다.

```mermaid
flowchart LR
    A[루멘 페이즈] --> B[레디 페이즈]
    B --> C[배틀 페이즈]
    C --> D[겟 페이즈]
    D --> E[리커버리 페이즈]
    E --> A
```

## 4.1 턴과 페이즈

<a id="rule-5-1-1"></a>
**4.1.1** 턴은 루멘 페이즈부터 리커버리 페이즈까지의 다섯 페이즈를 포함한다.

<a id="rule-5-1-2"></a>
**4.1.2** 한 턴은 루멘 페이즈, 레디 페이즈, 배틀 페이즈, 겟 페이즈, 리커버리 페이즈 순서로 진행한다.

## 4.2 루멘 페이즈

<a id="rule-5-2-1"></a>
**4.2.1** 루멘 페이즈에는 “루멘 페이즈에” 처리한다고 기재된 카드 효과를 우선권 보유자부터 처리한다.

## 4.3 레디 페이즈

<a id="rule-5-3-1"></a>
**4.3.1** 레디 페이즈에 각 플레이어는 사용할 기술 카드 1장을 골라 배틀 존에 뒷면으로 놓고 레디를 선언한다. 레디를 선언한 뒤에는 그 카드를 바꾸거나 선언을 취소할 수 없다.

> [!IMPORTANT]
> 한 번 레디를 선언하면 상대가 아직 레디하지 않았더라도 카드를 바꿀 수 없습니다. 대회·운영 규정의 10초 미대응 시간도 상대의 명확한 레디 선언 시점부터 계산합니다.

## 4.4 배틀 페이즈

<a id="rule-5-4-1"></a>
**4.4.1** 배틀 페이즈에 양쪽의 레디 카드를 동시에 앞면으로 공개하고 공격·수비 결과를 판정한다.

<a id="rule-5-4-2"></a>
**4.4.2** 배틀 페이즈 종료 시 레디한 카드를 패로 가져온다. 콤보·캐치·브레이크 등 별도 이동 규칙이 있으면 그 규칙을 우선한다. 양쪽 레디 카드는 우선권 보유자의 카드부터 사용된 것으로 취급한다.

## 4.5 겟 페이즈

<a id="rule-5-5-1"></a>
**4.5.1** 겟 페이즈에 진입할 때 발생하는 효과를 모두 처리한 뒤 우선권을 다시 결정한다. 이때 정한 순서는 그 겟 페이즈가 끝날 때까지 다시 계산하지 않는다.

<a id="rule-5-5-2"></a>
**4.5.2** 겟 페이즈에는 진입 시 결정한 우선권 보유자부터 리스트의 카드 1장을 상대에게 보여 준 뒤 패에 넣는다.

<a id="rule-5-5-3"></a>
**4.5.3** 패가 패 매수 상한에 도달한 플레이어는 겟 행동을 하지 않을 수 있다. 한 플레이어만 스킵해도 다른 플레이어의 겟은 스킵되지 않는다.

<a id="rule-5-5-4"></a>
**4.5.4** 겟 페이즈에 리스트 카드 1장을 가져오는 대신 얼티밋 존의 얼티밋 공격·수비 기술 1장을 패에 넣을 수 있다.

<a id="rule-5-5-5"></a>
**4.5.5** 겟 페이즈에 리스트 카드가 없으면 리스트에서 카드를 가져올 수 없지만 겟 페이즈 자체는 진행한다. 이 경우에도 얼티밋 존의 얼티밋 공격·수비 기술을 패에 넣는 행동은 할 수 있다.

## 4.6 리커버리 페이즈

<a id="rule-5-6-1"></a>
**4.6.1** 리커버리 페이즈에는 먼저 “턴 종료 시” 유발 효과를 처리한다. 그 뒤 그 턴 동안의 지속 효과와 “턴 종료 시까지” 효과를 종료하고 턴 종료를 선언한다.

<a id="chapter-5"></a>
# 5. 게임 종료

## 5.1 승리와 패배

<a id="rule-1-1-1"></a>
**5.1.1** 각 플레이어는 캐릭터 카드의 가장 왼쪽에 표시된 체력으로 시작한다. 처리 단위 종료 후 상대의 체력이 0 이하이고 자신의 체력이 1 이상인 상태가 확인되면 그 플레이어가 승리한다.

## 5.2 서든 데스

<a id="rule-12-2-1"></a>
**5.2.1** 같은 효과 또는 같은 판정 결과 처리 단위가 끝난 시점에 양쪽 체력이 모두 0 이하라면, 두 플레이어의 체력이 동시에 0이 된 것으로 보고 서든 데스를 진행한다.

<a id="rule-12-2-2"></a>
**5.2.2** 서든 데스가 되면 일반적인 새 게임 준비와 같은 절차로 패·리스트·사이드 덱을 다시 구성한다. 다만 양쪽 시작 체력은 1000이고, 시작 패는 체력 1000에서의 패 매수 상한과 같은 매수로 구성한다.

<a id="rule-12-2-3"></a>
**5.2.3** 서든 데스의 초기 패와 리스트도 서로 확인·공개하는 일반 준비 절차를 따른다. 초기 패 매수만 5장이 아니라 체력 1000에서의 패 매수 상한으로 바뀐다.

<a id="rule-12-2-4"></a>
**5.2.4** 서든 데스 시작 시 양쪽 FP를 0으로 한다.

<a id="rule-12-2-5"></a>
**5.2.5** 서든 데스는 기존 우선권 보유자가 우선권을 유지한 채 루멘 페이즈부터 3턴 진행한다. 3번째 턴 종료 시 체력이 더 높은 플레이어가 승리하고, 체력이 같으면 무승부로 처리한다.

<a id="rule-12-2-6"></a>
**5.2.6** 서든 데스 상태에서 양쪽 체력이 다시 동시에 0이 되면 게임을 무승부로 처리한다.

<a id="chapter-6"></a>
# 6. 카드의 효과와 우선권

## 6.1 기능·효과·생략 문법

<a id="rule-1-3-1"></a>
**6.1.1** 카드 설명에서 문장 앞에 번호가 없는 설명은 **기능**이다. 기능은 별도 발동 없이 항상 적용되며, 카드가 어느 존에 있든 적용한다.

<a id="rule-1-3-2"></a>
**6.1.2** 카드 설명에서 문장 앞에 번호가 있는 설명은 **효과**다.

<a id="rule-1-3-3"></a>
**6.1.3** 효과의 대상 또는 주체가 생략되면 다음과 같이 해석한다.

- 행동의 주체는 그 카드의 소유자인 플레이어 **자신**으로 본다.
- 카드의 상태·수치·이동을 가리키는 표현은 **이 카드**로 본다.

> [!EXAMPLE]
> - “상쇄 시”는 “자신이 상쇄 시”로 해석합니다.
> - “루멘 존의 카드를”은 “자신의 루멘 존의 카드를”로 해석합니다.

## 6.2 처리 단위와 상태 확인

<a id="rule-0-3-1"></a>
**6.2.1** “처리 단위”란 다음 중 하나를 뜻한다. `[편집 정의]`

- 번호 하나로 구분된 효과 하나를 처음부터 끝까지 처리하는 범위
- 양쪽 FP 또는 양쪽 데미지처럼 동시에 적용하도록 정해진 수치 처리 한 묶음

<a id="rule-0-3-2"></a>
**6.2.2** 각 처리 단위가 끝나면 체력 0, 패 매수 상한 초과 등의 상태를 확인한다. 필요한 상태 처리를 모두 수행한 뒤 다음 효과 또는 다음 단계로 진행한다.

<a id="rule-0-3-3"></a>
**6.2.3** 현재 처리 중인 효과는 일반 유발 효과 때문에 중단하지 않는다. 카드 텍스트 또는 공식 판정에서 명시적으로 “끼어들기”로 분류한 처리만 현재 효과 사이에 들어갈 수 있다.

> [!EXAMPLE]
> 한 효과가 양쪽 체력을 각각 500 감소시켰다면 그 효과 전체를 끝낸 뒤 양쪽 체력을 확인합니다. 양쪽 모두 0 이하라면 같은 처리 단위에서 동시에 체력 0이 된 것으로 봅니다.

## 6.3 우선권

<a id="rule-6-1-1"></a>
**6.3.1** 우선권은 같은 타이밍에 행동해야 할 때 먼저 행동할 권한이다.

<a id="rule-6-1-2"></a>
**6.3.2** 우선권은 다음 순서로 비교한다.

1. FP가 높은 플레이어
2. FP가 같으면 체력이 높은 플레이어
3. 체력도 같으면 패가 많은 플레이어

<a id="rule-6-1-3"></a>
**6.3.3** 우선권을 다시 결정할 때 FP·체력·패가 모두 같으면 이전 우선권 보유자가 우선권을 유지한다. 이 규칙은 겟 페이즈뿐 아니라 모든 우선권 재결정에 적용한다.

## 6.4 동시에 처리할 효과

<a id="rule-6-2-1"></a>
**6.4.1** 한 타이밍에 양쪽이 처리할 효과가 여러 개 있으면 우선권 보유자부터 번갈아 한 개씩 처리한다. 자기 차례가 된 플레이어는 자신이 처리할 수 있는 효과 중 하나를 선택한다. 상대에게 처리할 효과가 없으면 현재 효과의 처리가 끝난 뒤 같은 플레이어가 다음 효과 하나를 선택한다.

> [!EXAMPLE]
> A가 우선권을 가지고 A의 대기 효과가 2개, B의 대기 효과가 3개라면 `A → B → A → B → B` 순으로 처리합니다. 각 차례의 플레이어가 자신의 대기 효과 중 하나를 고릅니다.

<a id="rule-6-2-2"></a>
**6.4.2** 앞면 카드에서 발동하는 효과는 **공개 유발**, 뒷면 등 비공개 정보에서 발동하는 효과는 **비공개 유발**로 취급한다.

<a id="rule-6-2-3"></a>
**6.4.3** 같은 타이밍에 공개 유발과 비공개 유발을 모두 처리할 수 있으면 공개 유발 그룹을 먼저 처리한다. 각 그룹 안에서는 우선권과 효과 선택 규칙에 따라 처리한다.

## 6.5 강제 효과와 임의 효과

<a id="rule-6-3-1"></a>
**6.5.1** “~한다”는 강제 효과이고 “~할 수 있다”는 임의 효과다. 플레이어가 자신의 효과 처리 차례에 임의 효과를 사용하지 않고 넘기면, 같은 타이밍 동안 그 효과를 다시 사용할 수 없다.

## 6.6 텍스트 충돌

<a id="rule-6-4-1"></a>
**6.6.1** 강제형 텍스트가 충돌하면 “할 수 없다”처럼 어떤 행동을 불가능하게 하는 부정형을 우선한다.

<a id="rule-6-4-2"></a>
**6.6.2** 부정형 이외의 강제형 텍스트가 충돌하면 우선권 보유자의 효과를 먼저 적용한다. 먼저 적용된 효과와 모순되는 뒤의 효과는 모순되는 범위에서 적용하지 않는다.

## 6.7 끼어들기와 대기 효과

<a id="rule-6-5-1"></a>
**6.7.1** “끼어들기 효과”는 카드 텍스트 또는 공식 판정에서 끼어들기로 지정된 효과다. 그 밖의 유발 효과는 현재 처리 단위가 끝난 뒤 대기 중인 효과로 처리한다. `[표기 방식 확인 필요]`

> [!WARNING]
> 기존 카드에서 끼어들기 효과를 어떤 문구·아이콘으로 식별할지는 아직 정해지지 않았습니다. 카드 판정집에서 카드별 분류를 제공하거나 공통 표기법을 추가해야 합니다.

## 속도 용어

| 용어 | 정의 | 주로 사용하는 곳 |
|---|---|---|
| 인쇄 속도 | 카드에 인쇄된 원래 속도 | 기본 정보 |
| 참조 속도 | 카드 효과의 증감·고정을 반영하고 FP는 반영하지 않은 속도 | 회피·방어·상쇄 조건, 콤보 연결 |
| 판정 속도 | 참조 속도에 FP를 반영한 최종 속도 | 공격 대 공격의 빠르기 비교 |

> [!NOTE]
> “참조 속도”와 “판정 속도”는 기존 룰북의 FP 적용 전·후 속도를 명확하게 구분하기 위한 편집 용어입니다.

## 7.1 배틀의 전체 순서

<a id="rule-7-1-1"></a>
**7.1.1** 배틀은 양쪽 기술을 비교하여 판정승, 판정패 또는 무승부로 결정한다.

<a id="rule-7-1-2"></a>
**7.1.2** 배틀은 사용 시·판정 전 효과, FP 속도 보정, 전투 판정, 판정 시 효과, 판정 결과 FP와 데미지, 판정 후·사용 후 효과, 콤보, 캐치 순서로 진행한다.

<a id="rule-7-1-3"></a>
**7.1.3** 사용 시 효과를 우선권 보유자부터 처리한 뒤 판정 전 효과를 우선권 보유자부터 처리한다.

<a id="rule-7-1-4"></a>
**7.1.4** 전투 판정은 회피 확인, 방어 확인, 판정승·판정패 결정, 상쇄 확인 순서로 진행한다. 어떤 공격에 회피가 성립하면 그 공격에 대해서는 방어, 속도 승패, 상쇄 확인을 더 진행하지 않는다.

<a id="rule-7-1-5"></a>
**7.1.5** 그랩 무효 등 판정 결과를 무효로 하는 특수 처리는 히트 또는 카운터 판정을 확인한 직후, 그 판정의 효과를 처리하기 전에 선언하고 처리한다.

<a id="rule-7-1-6"></a>
**7.1.6** 전투 판정에 따른 효과는 회피 시, 방어 시, 히트·카운터 시, 상쇄 시, 콤보 시 순서로 적용한다.

<a id="rule-7-1-7"></a>
**7.1.7** “상대가 해당 판정을 했을 때” 발동하는 효과는 자신의 해당 판정 효과 뒤에 처리한다.

<a id="rule-7-1-8"></a>
**7.1.8** 양쪽 판정 결과에 따른 FP 변동을 모두 계산해 동시에 적용한 뒤, 양쪽 데미지를 모두 계산해 동시에 적용한다.

<a id="rule-7-1-9"></a>
**7.1.9** 판정 후 효과를 우선권 보유자부터 처리한 뒤 사용 후 효과를 우선권 보유자부터 처리한다.

## 7.2 속도와 FP

<a id="rule-7-2-1"></a>
**7.2.1** 공격 기술의 속도는 숫자가 낮을수록 빠르다.

<a id="rule-7-2-2"></a>
**7.2.2** 배틀에서 공격 기술의 속도를 비교할 때 플레이어의 현재 FP 전부를 적용한다. 양수 FP만큼 빨라지고, 음수 FP의 절댓값만큼 느려진다.

<a id="rule-7-2-3"></a>
**7.2.3** 레디한 카드가 공격인지 수비인지, 또는 속도가 고정되어 있는지와 관계없이 배틀에서 보유 FP 전부를 소모하고 양쪽 FP를 0으로 한다. 속도 고정 기술에는 FP에 의한 속도 변화만 적용되지 않는다.

<a id="rule-7-2-4"></a>
**7.2.4** 속도가 고정된 기술은 고정 이후 발생하는 FP와 다른 속도 변화의 영향을 받지 않는다. 속도 변화가 먼저 적용된 뒤 고정되었다면 이미 적용된 변화는 취소되지 않는다.

<a id="rule-7-2-5"></a>
**7.2.5** “X 속도로 고정한다”는 기술 속도를 X로 변경한 뒤 고정 상태를 적용한다.

<a id="rule-7-2-6"></a>
**7.2.6** “빨라진다”는 속도 수치를 낮추고 “느려진다”는 속도 수치를 높인다. 기술이 고정되지 않았다면 이후 FP 보정을 받는다.

<a id="rule-7-2-7"></a>
**7.2.7** 회피·방어·상쇄 조건에서 기술 속도를 참조할 때는 FP가 적용되지 않은 참조 속도를 사용한다.

<a id="rule-7-2-8"></a>
**7.2.8** 속도는 13을 초과하거나 5 미만으로 변할 수 있다. 계산 결과가 0 이하가 되면 실제 속도는 1로 처리한다.

<a id="rule-7-2-9"></a>
**7.2.9** 서로 다른 속도 고정 효과가 충돌하면 효과 처리 순서상 먼저 적용된 고정을 유지하고, 뒤의 고정은 모순되는 범위에서 적용하지 않는다.

> [!EXAMPLE]
> 속도 8 공격을 +3FP 상태에서 사용하면 판정 속도는 5입니다. -4FP 상태라면 판정 속도는 12입니다. 속도가 고정된 기술도 FP는 전부 소모하지만 속도에는 반영하지 않습니다.

## 7.3 공격 대 공격

<a id="rule-7-3-1"></a>
**7.3.1** 상대 기술에 자신의 공격 위치를 막는 유효한 방어·회피가 없으면 자신의 공격은 히트한다.

<a id="rule-7-3-2"></a>
**7.3.2** 히트한 공격은 히트 판정과 관련 효과를 적용하고 데미지를 준다. 히트 판정이 콤보이면 콤보 타임을 진행한다.

<a id="rule-7-3-3"></a>
**7.3.3** 공격 기술끼리 비교할 때 상대 공격의 판정 속도가 더 느리거나 상대 공격을 특수 판정으로 회피하면 자신의 공격은 카운터한다.

<a id="rule-7-3-4"></a>
**7.3.4** 카운터한 공격은 카운터 판정과 관련 효과를 적용하고 데미지를 준다. 카운터 판정이 콤보이면 콤보 타임을 진행한다.

<a id="rule-7-3-5"></a>
**7.3.5** 상대 공격이 자신의 공격보다 판정 속도가 빠르거나 상대 특수 판정으로 자신의 공격이 회피되면 자신의 공격은 카운터당한다.

<a id="rule-7-3-6"></a>
**7.3.6** 특수 판정으로 회피되어 카운터당한 공격은 “상대 회피 시” 효과를 적용하고 데미지를 주지 않는다.

<a id="rule-7-3-7"></a>
**7.3.7** 카운터당한 기술은 판정패로 취급한다.

<a id="rule-7-3-8"></a>
**7.3.8** 카운터되었을 때 발동하지 않는 “무효화를 조건으로 하는 기능”은 “이 카드가 무효가 되지 않았다면”처럼 무효 여부를 명시적으로 조건으로 적은 문구만 뜻한다.

<a id="rule-7-3-9"></a>
**7.3.9** 자신의 공격 특수 판정으로 상대 공격을 회피하고 공격에 성공하면 히트가 아니라 카운터 판정을 적용한다.

## 7.4 공격 대 수비

<a id="rule-7-4-1"></a>
**7.4.1** 수비 기술의 방어 또는 회피 위치 판정이 상대 공격의 위치 판정과 일치해야 해당 판정이 유효하다.

<a id="rule-7-4-2"></a>
**7.4.2** 수비 카드의 방어 위치가 상대 공격 위치와 일치하면 방어한다. 방어 시 효과를 적용하고 상대 공격 데미지를 적용하지 않는다.

<a id="rule-7-4-3"></a>
**7.4.3** 수비 카드의 회피 위치가 상대 공격 위치와 일치하면 회피한다. 회피 시 효과를 적용하고 상대 공격 데미지를 적용하지 않는다.

<a id="rule-7-4-4"></a>
**7.4.4** 상대 카드의 방어 위치가 자신의 공격 위치와 일치하면 자신의 공격은 방어된다. “상대 방어 시” 효과를 적용하고 데미지를 주지 않으며, 가드 판정을 FP에 적용한다.

<a id="rule-7-4-5"></a>
**7.4.5** 상대 카드의 회피 위치가 자신의 공격 위치와 일치하면 자신의 공격은 회피된다. “상대 회피 시” 효과를 적용하고 데미지를 주지 않는다.

<a id="rule-7-4-6"></a>
**7.4.6** 상대 공격 위치와 일치하는 유효한 수비 판정이 없으면 수비 카드는 히트당하며 방어·회피 효과를 적용하지 않는다.

## 7.5 무승부와 상쇄

<a id="rule-7-5-1"></a>
**7.5.1** 공격 기술끼리 FP 보정 후 판정 속도가 같으면 동시히트가 된다.

<a id="rule-7-5-2"></a>
**7.5.2** 동시히트에서는 양쪽 공격의 히트 관련 효과를 우선권 순으로 처리한다. 그 뒤 양쪽의 FP 변동을 동시에 적용하고, 이어서 양쪽 데미지를 동시에 적용한다.

<a id="rule-7-5-3"></a>
**7.5.3** 공격 또는 수비 기술의 상쇄 판정이 조건을 충족하면 배틀은 상쇄로 처리한다.

<a id="rule-7-5-4"></a>
**7.5.4** 공격 기술의 상쇄 위치가 상대 공격 위치와 같고 자신의 공격 속도가 상대 공격보다 느릴 때 공격 상쇄가 발생한다.

<a id="rule-7-5-5"></a>
**7.5.5** 수비 기술의 상쇄 위치가 상대 공격 위치와 같으면 수비 상쇄가 발생한다.

<a id="rule-7-5-6"></a>
**7.5.6** “상쇄 판정을 가진 기술의 속도가 상대 기술과 같거나 빠르면 발동하지 않는다”는 제한은 공격 기술의 상쇄에만 적용한다. 수비 기술의 상쇄에는 속도 비교를 적용하지 않는다.

<a id="rule-7-5-7"></a>
**7.5.7** 상쇄 시 양쪽 공격의 히트 시 효과를 처리한 뒤 상쇄 시 효과를 처리한다. 이어서 판정 결과 FP를 동시에 적용하고, 양쪽 공격 데미지의 차이만큼 데미지가 낮은 쪽의 체력을 감소시킨다.

<a id="rule-7-5-8"></a>
**7.5.8** 수비 기술의 데미지는 0으로 계산하고, 수비 기술에는 히트 판정이 없는 것으로 취급한다.

<a id="rule-7-5-9"></a>
**7.5.9** 양쪽이 모두 수비 기술을 사용하면 히트·카운터·방어·회피 시 효과를 적용하지 않는다. 사용 시, 판정 전, 판정 후, 사용 후 등 판정 결과와 무관하게 조건을 만족한 효과만 처리한다.

<a id="rule-7-5-10"></a>
**7.5.10** 양쪽 공격이 서로를 회피하면 그 배틀은 무승부가 되며 회피 시 유발 효과를 처리하고 회피된 공격의 데미지는 적용하지 않는다.

<a id="rule-7-5-11"></a>
**7.5.11** “서로 방어”는 두 플레이어가 모두 수비 기술 카드를 사용한 경우만 뜻한다. 이 배틀은 무승부이며 방어 시 효과는 발동하지 않는다.

## 7.6 판정 결과 FP

<a id="rule-7-6-1"></a>
**7.6.1** 공격 기술에는 히트·방어됨·카운터 결과에 따른 FP 증감치가 각각 표시된다.

## 7.7 데미지

<a id="rule-7-7-1"></a>
**7.7.1** 공격 기술이 히트하거나 카운터하면 카드에 표시된 데미지만큼 상대 체력을 감소시킨다.

<a id="rule-7-7-2"></a>
**7.7.2** 방어 성공 시 입는 가드 데미지는 그 수비 기술 카드가 발생시킨 데미지이며, 그 카드의 소유자가 자신에게 입힌 데미지로 취급한다. 따라서 “자신이 데미지를 입었을 때” 조건은 충족하지만 “상대가 데미지를 주었을 때” 조건은 충족하지 않는다.

## 7.8 사용 카드의 정리

<a id="rule-7-8-1"></a>
**7.8.1** 배틀에 사용한 기술은 사용한 순서대로 패로 회수한다. 양쪽 레디 카드는 우선권 보유자의 카드가 먼저 사용된 것으로 취급한다. 콤보·캐치 카드는 리스트로, 효과로 브레이크된 카드는 브레이크 존으로 보낸다.

## 7.9 특수 판정과 그랩

<a id="rule-7-9-1"></a>
**7.9.1** 특수 판정은 카드가 가지는 특수한 판정이며 회피, 상쇄, 그랩 등의 키워드가 있다.

<a id="rule-7-9-2"></a>
**7.9.2** 상대 그랩 기술의 히트·카운터 판정을 적용할 때 자신의 패에서 그랩 기술 1장을 브레이크하면 그랩을 무효로 할 수 있다.

<a id="rule-7-9-3"></a>
**7.9.3** 그랩을 무효로 하면 남은 처리를 하지 않고 양쪽 레디 카드를 패로 되돌린 뒤 같은 턴의 레디 페이즈를 다시 진행한다. 이미 처리한 사용 시 효과와 FP 변동은 되돌리지 않는다.

> [!IMPORTANT]
> 그랩 무효는 배틀 전체를 되감는 처리가 아닙니다. 이미 처리한 사용 시 효과와 FP는 유지하고, 아직 처리하지 않은 판정 효과·데미지만 중단합니다.

## 콤보

콤보는 히트 또는 카운터의 콤보 판정이나 카드 효과로 시작하는 연속 공격 절차입니다.

## 콤보 보정표

| 콤보 번호 | 연결 조건 | 데미지 보정 |
|---|---|---:|
| 1콤보 | 콤보를 발생시킨 공격 또는 효과가 지정한 첫 카드 | 0 |
| 2콤보 | 기본 콤보에서 임의의 합법적 공격 | -100 |
| 3콤보 | 2콤보보다 속도 수치가 정확히 1 큼 | -200 |
| 4콤보 이상 | 직전 카드보다 속도 수치가 정확히 1 큼 | 콤보 번호가 1 늘 때마다 추가 -100 |

## 8.1 콤보 진입과 합법성

<a id="rule-8-1-1"></a>
**8.1.1** 콤보 판정인 공격이 히트하거나 카운터하면 그 공격을 1콤보로 하여 콤보 타임을 시작한다.

<a id="rule-8-1-2"></a>
**8.1.2** 콤보로 제시한 카드는 앞선 카드의 처리가 끝난 뒤 실제로 사용 가능한 상태여야 한다. 합법적이지 않은 선언은 그 카드를 사용하지 않은 것으로 취급하고 패로 되돌리며, 같은 콤보 단계에 다른 합법적인 카드를 다시 제시할 수 있다.

<a id="rule-8-1-3"></a>
**8.1.3** 불법 콤보 선언으로 사용되지 않은 카드는 패의 비공개 정보로 되돌아가지만, 이미 공개된 정보 자체를 없었던 것으로 만들지는 않는다. `[편집 명문화]`

## 8.2 콤보 공통 처리

<a id="rule-8-2-1"></a>
**8.2.1** 콤보 카드는 사용 시, 콤보 시, 데미지 처리, 사용 후 효과 순서로 처리한다.

<a id="rule-8-2-2"></a>
**8.2.2** 콤보에 사용한 카드는 히트·카운터 판정을 적용하지 않는다.

<a id="rule-8-2-3"></a>
**8.2.3** 2콤보는 100, 3콤보는 200, 이후 콤보 수가 하나 늘 때마다 100씩 카드 데미지를 감소시킨다.

<a id="rule-8-2-4"></a>
**8.2.4** 콤보 시 효과를 처리한 뒤 데미지 보정 결과 데미지가 0 이하가 되면 그 기술은 콤보에 사용할 수 없다.

<a id="rule-8-2-5"></a>
**8.2.5** 콤보에 사용한 모든 카드는 1콤보를 포함해 콤보 종료 시 리스트로 보낸다.

<a id="rule-8-2-6"></a>
**8.2.6** 콤보 타임이 시작되면 그 배틀 페이즈의 캐치 기회는 사라진다. 콤보 타임이 종료되면 배틀 페이즈를 즉시 종료한다.

<a id="rule-8-2-7"></a>
**8.2.7** 콤보 시 효과 처리 뒤 데미지가 0 이하가 된 카드의 사용 취소, 이미 처리한 효과의 되돌림, 재선택 범위는 추가 공식 결정이 필요하다. 그 전까지는 해당 카드를 사용할 수 없다는 결론만 적용한다. `[확인 필요]`

> [!WARNING]
> 0 데미지 이하가 된 카드의 효과를 되돌리는지, 카드를 패로 돌리는지, 다른 카드를 다시 낼 수 있는지는 아직 확정되지 않았습니다.

## 8.3 기본 콤보 연결

<a id="rule-8-3-1"></a>
**8.3.1** 1콤보 후 그 플레이어는 콤보 타임을 종료하거나, 패에서 임의의 공격 카드와 그 카드보다 속도 수치가 정확히 1 큰 공격 카드를 순서대로 제시할 수 있다. 두 카드를 제시하면 각각 2콤보와 3콤보가 된다.

<a id="rule-8-3-2"></a>
**8.3.2** 합법적으로 사용할 수 있는 2콤보와 3콤보 두 장을 모두 제시할 수 없으면 콤보 타임을 종료한다.

<a id="rule-8-3-3"></a>
**8.3.3** 3콤보 이후에는 직전 콤보 카드보다 속도 수치가 1 큰 공격 카드를 한 장씩 계속 사용할 수 있다.

## 8.4 콤보 특수 처리

<a id="rule-8-4-1"></a>
**8.4.1** 2·3콤보로 사용할 카드가 없어도 콤보 타임은 시작되며 1콤보 카드는 종료 시 리스트로 보낸다.

<a id="rule-8-4-2"></a>
**8.4.2** 콤보 타임 종료 시 양쪽 FP를 0으로 한다.

<a id="rule-8-4-3"></a>
**8.4.3** 히트·카운터가 아닌 효과로 콤보 타임에 진입하면 조건을 만족하는 공격 카드 두 장을 순서대로 제시해 각각 1콤보와 2콤보로 사용할 수 있다. 두 장을 모두 제시할 수 없으면 아무 카드도 사용하지 않고 콤보 타임을 종료한다.

<a id="rule-8-4-4"></a>
**8.4.4** 콤보에서 카드를 특정 속도로 취급해 사용했다면 다음 카드는 그 취급 속도보다 수치가 1 큰 카드여야 한다.

<a id="rule-8-4-5"></a>
**8.4.5** 콤보 중 카드 효과로 공격 기술의 속도가 변하면 변동된 속도를 기준으로 다음 콤보를 연결한다.

<a id="rule-8-4-6"></a>
**8.4.6** 콤보 처리 중 브레이크가 발생하면 콤보를 일시 중지하고 브레이크 및 즉시 보충 처리를 마친 뒤 콤보를 재개한다. 단, 2콤보와 3콤보의 한 쌍은 두 카드 모두 합법적으로 사용할 수 있는 조합이어야 한다.

<a id="rule-8-4-7"></a>
**8.4.7** 2콤보와 3콤보는 함께 제시하지만 순서대로 사용한다. 2콤보의 처리 결과를 적용한 뒤에도 3콤보가 합법적으로 사용 가능해야 하며, 그렇지 않은 조합은 처음부터 제시할 수 없다.

<a id="rule-8-4-8"></a>
**8.4.8** 콤보 중 새 효과가 유발되면, 그 효과가 카드 또는 공식 판정에서 “끼어들기”로 분류된 경우 현재 처리를 중단하고 즉시 처리한다. 일반 유발 효과는 현재 효과의 처리 단위가 끝난 뒤 처리한다.

<a id="rule-8-4-9"></a>
**8.4.9** 2콤보와 3콤보를 함께 제시할 때, 2콤보의 의무 효과를 적용한 뒤 3콤보가 사용 조건과 연결 속도를 모두 만족하도록 조합해야 한다.

> [!WARNING]
> 합법적으로 선언한 2·3콤보가 예상하지 못한 끼어들기 효과 때문에 불법이 된 경우 어느 카드까지 되돌리는지는 카드별 추가 판정이 필요할 수 있습니다.

## 8.5 동시히트·상쇄 콤보

<a id="rule-8-5-1"></a>
**8.5.1** 동시히트한 양쪽 공격이 모두 콤보 판정이면 각 플레이어의 1콤보는 이미 확정된 것으로 본다. 효과는 우선권 순으로 처리하고 데미지는 동시에 적용하며, 어느 한쪽 체력이 먼저 0이 된 것처럼 취급해 다른 쪽 1콤보를 중단하지 않는다. 양쪽은 각각 1콤보만 처리하고 콤보 타임을 종료한다.

<a id="rule-8-5-2"></a>
**8.5.2** 상쇄된 양쪽 공격이 모두 콤보 판정이면 각 플레이어는 1콤보만 처리하고 콤보 타임을 종료한다.

캐치는 배틀 말미에 FP 상태 또는 카드 효과로 발생하는 자동 히트 공격입니다.

## 캐치 종류

| 종류 | 조건 | 사용할 카드 |
|---|---|---|
| 양수 FP 캐치 | 자신 FP > 0, 상대 FP = 0 | 자신이 얻은 FP 이하의 속도 수치인 공격 |
| 음수 FP 캐치 | 자신 FP = 0, 상대 FP < 0 | 상대가 잃은 FP 절댓값 이하의 속도 수치인 공격 |
| 효과 캐치 | 카드 효과가 캐치를 지시 | 효과가 정한 조건의 공격 |

## 8.6 캐치 조건

<a id="rule-9-1-1"></a>
**8.6.1** 캐치는 배틀의 모든 기술이 사용 후 효과까지 처리된 뒤, 배틀 페이즈가 끝나기 전에 조건을 만족하면 진행할 수 있다.

<a id="rule-9-1-2"></a>
**8.6.2** 자신의 FP가 0보다 크고 상대 FP가 0이면 자신이 얻은 FP 이하의 속도 수치를 가진 공격 기술을 패에서 사용하여 캐치할 수 있다.

<a id="rule-9-1-3"></a>
**8.6.3** 자신의 FP가 0이고 상대 FP가 0보다 작으면 상대가 잃은 FP의 절댓값 이하의 속도 수치를 가진 공격 기술을 패에서 사용하여 캐치할 수 있다.

<a id="rule-9-1-4"></a>
**8.6.4** 카드 효과가 “캐치한다”고 지시하면 그 효과가 지정한 조건을 만족하는 공격 기술을 사용하여 캐치한다.

## 8.7 캐치 처리

<a id="rule-9-2-1"></a>
**8.7.1** 캐치를 진행하면 양쪽 FP를 0으로 한다.

<a id="rule-9-2-2"></a>
**8.7.2** 캐치에 사용한 공격은 자동으로 히트하고 히트 판정과 관련 효과를 적용한다. 캐치 공격은 그랩 무효 외의 방어·회피·상쇄로 막을 수 없다. 히트 판정이 콤보이면 콤보 타임에 진입한다.

<a id="rule-9-2-3"></a>
**8.7.3** 캐치 카드는 사용 시, 캐치 시, 히트 시, 데미지 처리, 사용 후 효과 순서로 처리하며 판정 전 효과는 적용하지 않는다.

<a id="rule-9-2-4"></a>
**8.7.4** 캐치에 사용한 공격 카드는 배틀 페이즈 종료 시 리스트로 보낸다.

## 8.8 연속 캐치와 특수 상황

<a id="rule-9-3-1"></a>
**8.8.1** 한 플레이어가 캐치를 시작하면 그 캐치 타임 동안 캐치 권리는 그 플레이어에게만 있다. 캐치 종료 후에도 조건을 다시 만족하면 같은 플레이어가 연속해서 캐치할 수 있다.

<a id="rule-9-3-2"></a>
**8.8.2** 그랩 공격을 캐치로 사용해도 상대는 패의 그랩 카드를 브레이크하여 그 공격을 무효로 할 수 있다.

<a id="rule-9-3-3"></a>
**8.8.3** 캐치로 사용한 그랩을 무효로 하면 본래 배틀의 데미지·FP·카드 이동 결과는 유지한다. 무효된 캐치 카드만 패로 되돌리고 같은 턴의 레디 페이즈를 다시 진행한다.

<a id="rule-9-3-4"></a>
**8.8.4** 효과에 의한 캐치는 FP와 무관하게 먼저 처리한다. 그 후 FP에 의한 캐치가 가능하면 추가로 선언할 수 있다.

<a id="rule-9-3-5"></a>
**8.8.5** 양쪽 모두 캐치할 수 있으면 우선권 보유자가 먼저 캐치한다. 그 플레이어가 캐치를 시작하면 상대의 캐치 권리는 그 캐치 타임이 끝날 때까지 사라진다. 그랩 무효 등으로 레디 페이즈를 다시 진행하면 이 제한은 사라진다.

<a id="chapter-9"></a>
# 9. 규칙에 의한 효과

## 9.1 존 이동과 버리기

<a id="rule-10-1-1"></a>
**9.1.1** 브레이크된 카드는 브레이크 존으로 보낸다.

<a id="rule-10-1-2"></a>
**9.1.2** “버린다”는 패의 카드를 리스트에 앞면으로 놓는 것을 뜻하며 브레이크와 다르다.

## 9.2 브레이크와 보충

<a id="rule-10-2-1"></a>
**9.2.1** 패·리스트·루멘 존·배틀 존에서 공격 또는 수비 기술이 브레이크되면 그 직후 즉시 보충 처리를 끼워 넣는다. 그 카드의 주인은 사이드 덱의 공격 또는 수비 기술 1장을 리스트에 앞면으로 놓을 수 있다. 적합한 카드가 없거나 이동이 불가능하면 보충하지 않는다.

<a id="rule-10-2-2"></a>
**9.2.2** 브레이크된 기술은 일반적으로 그 게임에서 더 이상 사용할 수 없다.

<a id="rule-10-2-4"></a>
**9.2.3** 얼티밋 공격·수비 기술이 브레이크되면 일반 공격·수비 기술과 동일하게 사이드 덱에서 리스트로 보충할 수 있다.

> [!EXAMPLE]
> 리스트가 이미 14장이라면 보충하려던 카드가 리스트로 이동하려는 순간 그 카드가 대신 브레이크됩니다. 이 카드는 사이드 덱에서 브레이크된 것이므로 추가 보충은 발생하지 않습니다.

## 9.3 특수 기술의 불법 이동

<a id="rule-10-3-1"></a>
**9.3.1** 특수 기술 카드가 패 또는 리스트로 이동하려 하면 그 이동을 브레이크 존으로의 이동으로 대체한다.

<a id="rule-10-3-2"></a>
**9.3.2** 특수 기술 카드가 브레이크되어도 사이드 덱에서 리스트로 카드를 보충하지 않는다.

<a id="rule-10-3-3"></a>
**9.3.3** 얼티밋 특수 기술은 사이드 덱, 루멘 존, 얼티밋 존, 브레이크 존에만 존재할 수 있다. 그 밖의 존으로 이동하려 하면 브레이크 존 이동으로 대체한다.

## 9.4 디펜스 오버

<a id="rule-12-1-1"></a>
**9.4.1** 연속된 세 번의 배틀 페이즈에서 다음 네 항목이 모두 없으면 디펜스 오버가 발생한다.

- 공격 기술 사용
- 데미지 발생
- FP 변동
- 효과 발동

네 항목 중 하나라도 발생하면 연속 횟수를 0으로 초기화한다. 효과가 실제 상태를 바꾸지 않았더라도 “효과 발동”이 있었다면 초기화한다.

<a id="rule-12-1-2"></a>
**9.4.2** 디펜스 오버가 발생하면 양쪽 배틀 존의 기술을 브레이크한다. 이 브레이크에도 일반 브레이크 보충 규칙을 적용한다. 같은 정체 상태가 네 번째 이후에도 계속되면 매 배틀마다 다시 처리한다.

# 부록 A. 용어집

| 용어 | 정의 |
|---|---|
| 공개 유발 | 앞면 카드 등 공개 정보에서 발동하는 효과 |
| 기능 | 번호 없는 카드 설명. 별도 발동 없이 모든 존에서 항상 적용 |
| 끼어들기 | 현재 효과의 처리 단위를 중단하고 먼저 처리하도록 공식 지정된 처리 |
| 데미지 보정 | 콤보 번호에 따라 카드 데미지를 100씩 추가 감소시키는 처리 |
| 레디 | 기술 카드를 배틀 존에 뒷면으로 놓고 선택을 확정하는 선언 |
| 리스트 | 최대 14장의 공개 기술 카드가 놓이는 존. “버린다”는 패에서 리스트로 이동하는 것 |
| 브레이크 | 카드를 브레이크 존으로 보내 그 게임에서 일반적으로 재사용하지 못하게 하는 처리 |
| 비공개 유발 | 사이드 덱 등 비공개 정보에서 발동하는 효과 |
| 사용 | 카드를 해당 절차에 따라 제시하고 사용 시 효과부터 처리하기 시작하는 것 |
| 상쇄 | 공격 또는 수비 기술의 상쇄 판정으로 양쪽 히트를 적용하고 데미지 차이를 처리하는 무승부 판정 |
| 속도 수치 | 공격 기술의 속도를 나타내는 숫자. 낮을수록 빠름 |
| 참조 속도 | 효과에 의한 속도 변화·고정을 반영하고 FP는 반영하지 않은 속도 |
| 판정 속도 | 참조 속도에 FP를 반영한 최종 속도 |
| 처리 단위 | 효과 하나 또는 동시에 적용하는 수치 한 묶음을 처음부터 끝까지 처리하는 범위 |
| 캐치 | 배틀 말미에 FP 또는 효과 조건으로 수행하는 자동 히트 공격 |
| 콤보 타임 | 콤보 판정 또는 카드 효과로 진입해 속도 수치가 이어지는 공격을 사용하는 절차 |
| 우선권 | 같은 타이밍에 양쪽이 행동할 때 먼저 효과를 선택·처리할 권한 |
| 효과 | 번호가 있는 카드 설명. “한다”는 강제, “할 수 있다”는 임의 |

<a id="appendix-b"></a>
# 부록 B. 빠른 참조표

## 한 턴의 흐름

`루멘 → 레디 → 배틀 → 겟 → 리커버리`

| 페이즈 | 핵심 행동 |
|---|---|
| 루멘 | 루멘 페이즈 효과 처리 |
| 레디 | 기술 1장 선택·뒷면 배치·레디 선언 |
| 배틀 | 공개·판정·효과·콤보·캐치 |
| 겟 | 리스트 카드 또는 얼티밋 공격/수비 획득 |
| 리커버리 | 턴 종료 유발 처리 후 지속 효과 종료 |

## 배틀 처리 순서

`공개 → 사용 시 → 판정 전 → FP → 회피 → 방어 → 속도 승패 → 상쇄 → 특수 처리 → 판정 효과 → FP → 데미지 → 상태 확인 → 판정 후 → 사용 후 → 콤보 → 캐치 → 정리`

## 카드 조합별 핵심 결과

| 자신 \ 상대 | 공격 | 수비 |
|---|---|---|
| 공격 | 회피 확인 → 속도 비교 → 상쇄. 빠른 쪽이 카운터하고 같으면 동시히트 | 상대 수비 위치와 일치하면 방어·회피, 일치하지 않으면 히트 |
| 수비 | 자신의 수비 위치가 상대 공격과 일치하면 방어·회피, 일치하지 않으면 히트당함 | 서로 수비. 판정 결과와 무관한 효과만 처리 |

> [!IMPORTANT]
> 각 효과 또는 동시 수치 처리 한 묶음이 끝날 때 체력 0과 패 상한을 확인합니다. 콤보가 시작되면 그 배틀의 캐치 기회는 사라집니다.

# 부록 C. 편집 확인 목록

정식 종합 규칙 발행 전에 다음 항목을 확정해야 합니다.

- [ ] **문서 우선순위:** 정오표·카드 판정·카드 텍스트·종합 규칙·입문서·예시의 정확한 우선순위와 기준 언어
- [ ] **루멘 존 기본 공개 상태:** 배치 효과가 앞·뒷면과 공개 범위를 정하지 않았을 때 적용할 기본값
- [ ] **끼어들기 분류:** 어떤 카드 효과가 끼어들기인지 식별할 공통 문구, 아이콘 또는 카드별 판정 목록
- [ ] **0 데미지 콤보:** 콤보 시 효과 처리 뒤 데미지가 0 이하가 된 카드의 효과 되돌림, 패 복귀, 재선택과 콤보 종료 여부
- [ ] **2·3콤보 중 예외:** 합법적으로 선언한 2·3콤보가 예상하지 못한 끼어들기로 불법이 되었을 때 되돌리는 범위
- [ ] **표준 가상 기술:** 미대응 시 사용하는 가상 기술의 공격/수비 종류, 위치 판정, 속도 수치

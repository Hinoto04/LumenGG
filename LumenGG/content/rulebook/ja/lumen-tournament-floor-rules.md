## フロアルールとは

フロアルールは、大会やイベントですべてのプレイヤーが公正で楽しくゲームを楽しむことができるように定められた共通ルールです。

> 正当でクリーンなプレイで気持ちよくレディ、ファイト！

> [!IMPORTANT]
> ゲーム中にルールや効果処理に疑問が生じた場合、プレイヤーはジャージに判断を求めることができる。両方のプレイヤーが判断に反する場合、他のジャージーに裁判を要求することができますが、要求を受け入れるかどうかと最終判断の決定権はジャージにあります。

## クイックリファレンス

### 基本的な試合時間

| 区分 | 大会で別途指定していない場合 |
| --- | --- |
| スイスラウンド | ラウンドあたり30分、単版戦 |
| 本線 | ラウンドあたり30分、単版戦 |
| 3・4ウィジョン | ラウンドあたり30分、単版戦 |
| 決勝 | ゲームあたり25分、3版2 |

### プレイ中の主な時間

| 状況 | 時間 | 時間が経つと |
| --- | ---: | --- |
| 相手がレディーした後、自分のレディー | 10秒 | `対応なし` 1回累積対象 |
| ゲットフェイズのカードを選択 | 30秒 | カードをインポートしていないと見なしてアクションを終了 |
| ルーメン・リカバリーフェイズの効果処理宣言 | 30秒 | その効果を処理していないと考える |
| どちらもレディーしない状態 | ジャージーが30秒の制限を与えることができる | 最初の制限失敗時の両方の注意1回後に再び30秒、2回目も失敗すると双方敗北 |

### ペナルティ累積

- `注意` 3回累積時に`警告` 1回が課されます。
- `警告` 3回の累積時、該当大会やイベントで`失格`を行います。
- 違反の性質と程度によっては、`ゲームロス`、`失格`、`参加資格停止`が直接課されることがあります。
- 具体的な適用と最終判断は、ジャージまたは大会主催側が担当します。

<a id="floor-conduct"></a>
# 1. マナーと参加者の役割



相手を尊重し配慮する心で大会やイベントに参加します。

<a id="floor-player"></a>
## 1.1 プレイヤー

プレイヤーは以下を守らなければなりません。

- ゲーム中にどのカードをレディーしたのか、相手が確実に認知できるようにします。
- 効果を処理するときにどの効果をどのように処理するかを正確に認識できるようにします。
- リストが相手に正確に見えるように配置します。
- 相手のカード、プレイマット、トークン、補助具など所持品を丁寧に扱います。
- ゲーム中に手札を除く公開情報の確認が必要な場合は、相手の許可を得て確認します。
  - 例：ブレイクゾーンのカード確認
  - 例: ゲットフェイズ またはエフェクトにインポートするカードの確認
  - 例：バトルゾーンカードの正確な効果を確認する
- 相手が不快感を感じる行動をしてはいけません。
  - 大きな声で脅かす行為
  - ひとりで不快感を引き起こす言葉
  - わざわざ時間を切るプレイ
  - 非俗語の使用
- ゲーム中に席を空けるときは、相手プレイヤーとジャージーまたは大会主催側の許可を受けます。
- ルールや効果処理に疑問が生じた場合、ジャージに判断を求めることができます。

### ジャージー判断の再要求

- プレイヤーはジャージーの判断に従わなければなりません。
- 両方のプレイヤーが判断に反する場合、他のジャージーに裁判を求めることができます。
- 裁判所の要求の受け入れと最終判断の決定権はジャージーにあります。

<a id="floor-spectator"></a>
## 1.2 観戦者

- 観戦者は、ゲームや大会の運営に支障が生じないようにマナーを守らなければなりません。
- これを守らないと、ジャージまたは大会主催側の判断で観戦禁止や退場措置が行われることがあります。
- 観戦者は、進行中のゲームのルール判断に直接介入したり、ジャージーにルール問い合わせをすることはできません。関連状況は、実際のプレイヤーがジャージーに連絡する必要があります。

<a id="floor-judge"></a>
## 1.3 ジャージー（審判）

- ジャージーはルールを守り、公正で円満な大会運営が行われるように参加者と協力します。
- すべてのプレイヤーの模範になるように紳士的に対応します。
- プレイヤーのルール未熟地、不正行為、通念上迷惑になったり、大会運営に支障をきたすことができる行為を発見すると介入して指摘・訂正する権限があります。
- 誤ったルールや効果処理を発見した場合、別途お問い合わせがなくてもゲームに介入して正しい処理を要求し、内容に応じてペナルティを課すことができます。

<a id="floor-cards-and-supplies"></a>
# 2. カードと補助ツール



<a id="floor-legal-cards"></a>
## 2.1 利用可能なカード

次のカードを使用できます。

- ヤオニコミックで開発し、隊員メディアで流通するルーメンコンデンサーカード
- 使用キャラクターのキャラクターマークと同じマークのカード
- ニュートラルマークカード
- 式で使用を禁止していないカード
- ゲームに直接影響を与えない範囲の自作トークン

自作トークンを使用するときは、そのトークンがどのトークンまたは状態を表すかを相手に正確に知らせる必要があります。

<a id="floor-illegal-cards"></a>
## 2.2 使用できないカード

次のカードは使用できません。

- 違法コピーカード
- ヤオニコミックで開発し、隊員メディアで流通したことのないカード
- 正式発売されていないカード
- 式で使用を禁止したカード

<a id="floor-deck-change"></a>
## 2.3 大会中にデッキ編成とカード変更

- 大会中はデッキのカードを交換できません。
- カードが損傷して使用できない場合、またはカードの効果を読み取れない場合にのみ、そのカードなどの通常のカードと交換できます。

> [!NOTE]
> 原文は、破損・読取り不可カードの同一カード交換のみ例外とします。他の理由のデッキ変更手順は提示されません。

<a id="floor-marking"></a>
## 2.4 マーキング

マーキングは、前面を見ていない状態でカードがどのカードであるかを区別することを可能にするすべての方法を意味します。

いかなる場合でも、カードまたはプロテクターのマーキングは許可されません。

### マーキングの例

- カード裏面に落書きして区別できる場合
- カードの端を切り取ったり削ったりすることができる場合
- カードにステッカーなどの付着物を貼った場合
- ワックスなどを塗って触感で区別できる場合

### サインカード

- 裏面の状態でカードが特定されたり、正式流通カードと仕様が異なる場合は使用できません。
- サインが書かれたカードは公式大会・イベントで使用をお勧めしません。 使用で生じる不利益はプレイヤー本人の責任です。
- キャラクターカードと特性カード以外の技カードに前面・裏面を問わずサインがあればマーキングとみなして使用を禁止します。

<a id="floor-supplies"></a>
## 2.5 補助ツール（サプリメント）

### 非公式補助ツール

デッキ構成用のルーメンコンデンサーカードを除くと、ヤオニコミックや隊員メディアが発売していない物品も基本的に使用できます。

### プロテクター

- 特定のカードを区別することはできません。
- 光の反射で物体が鮮明に映らない材料を使用する必要があります。
- キャラクターカードと特性カードを除くデッキのすべての技カードは同じプロテクターを使用する必要があります。
- 透明スリーブを使用した場合、裏面の状態でカードが特定されるとジャージーや大会側が判断すると、直ちに交換、該当ゲームや大会の敗北、失格などの不利益が発生することがあります。
- できるだけカードの裏側が見えないスリーブを使用することをお勧めします。

### 使用できない補助ツール

次の補助ツールは使用できません。

- 国内法上成人物に指定されるなど、美風良俗にずれる画像が印刷されたもの
- 他人に拒否感を引き起こす画像が印刷されたもの
- 故人の冒涜や特定集団に対するヘイト行為など、悪意のある意図の画像が印刷されたもの
- ステッカーなどの付着物が付いているもの

ジャージや大会側の判断により、直ちに交換、該当ゲームや大会の失格など不利益が発生する場合があります。

<a id="floor-before-game"></a>
# 3. ゲーム開始前



## 3.1 最初の優先権決定

はさみロック、サイコロ、コイントースなど、両方のプレイヤーが合意したランダムな手段として最初の優先権保有者を決めます。

決定方法のために葛藤が生じたら、ジャージーの監督の下、はさみロックで決めます。

## 3.2 ゲーム開始前に確認

ゲームを始める前に、次の点を確認してください。

- **キャラクター・特性・アルティメット確認**
キャラクター、キャラクター、アルティメットカードを正確に認識できるように前面に置きます。
- **デッキ枚数確認**
自分のデッキ枚数を確認し、相手に正確な枚数を知らせます。
- **サイドデッキ確認**
リスト9章とスタートアップ5章を除くデッキのカードをサイドデッキにしてサイドデッキゾーンに置きます。サイドデッキ 枚数を相手に正確に知らせます。
- **スタート敗北確認**
スタートアップ5章を、ゲーム開始前に相手が正確に確認できるように示します。

### 開始前のチェックリスト

- [ ] キャラクター、特性、アルティメットが表側に公開されている。
- [ ] 最初の優先権を合意したランダムな方法で決定した。
- [ ] デッキ枚数を相手に知らせた。
- [ ]リスト9章と開始手札5章を除いたカードをサイドデッキに置いた。
- [ ] サイドデッキ 枚数を相手に知らせた。
- [ ] スタート敗 5章を互いに確認した。

<a id="floor-win-and-no-response"></a>
# 4. 勝敗判定課対応なし



## 4.1 フロアルールで指定された敗北条件

次のいずれかが発生すると、そのプレイヤーは敗北します。

- 片方のプレイヤーの体力が0になった場合
- 一方のプレイヤーが`対応なし`を3回累積した場合

同時に、体力が0になった場合と、制限時間終了時の処理は[7。大会制限時間と時間終了処理](#floor-match-time)を参照してください。

<a id="floor-no-response"></a>
## 4.2 対応なし(対応していないもの)

次の状況は`対応していないもの`として扱われ、`対応なし`を1回累積します。

- 相手がスキルをレディしてから10秒以内にレディしなかった場合
- レディーするスキルがない場合
- 使用条件を満たしていない技術をレディした場合

### 対応なし処理

1. 相手プレイヤーは、対応していないプレイヤーの手札を確認します。
2. 相手はその手札から希望のカード1章を選んでレディさせます。
3. レディできるスキルが全くない場合、防御判定のない防御技または速度が遅い攻撃技を使用したものとして扱います。
4. この場合、相手プレイヤーは自分の攻撃技に`ヒット`または`カウンター`のいずれかを選択することができます。

> [!WARNING]
> 原文は「防御判定のない防御技または速度が遅い攻撃技」と定めますが、その代替技術の正確なカード種類・位置・速度数値は提示しません。Web電卓や自動判定機は任意の数値を作ってはいけません。

## 4.3 意図的な対応なし

相手を挑発したり、技術使用ペナルティを回避するなど、プレイ上の利得を得るために意図的に対応しないことを選択したと疑われた場合、相手はジャージーに判断を求めることができる。

ジャージーが悪意のあると判断した場合は、次のものを一緒に適用できます。

- `対応なし` 1回の累積
- スポーツマンシップ違反に対する`警告`以上の追加ペナルティ

<a id="floor-phase-operation"></a>
# 5. フェーズごとの進行と制限時間



<a id="floor-ready-phase"></a>
## 5.1 レディフェイズ

- 一方のプレーヤーがスキルをレディーすると、もう一方のプレイヤーは10秒以内にレディーする必要があります。
- 必要に応じて、電子時計、スマートフォン、砂時計などの信頼できる手段で時間を計ることができます。

<a id="floor-ready-delay"></a>
## 5.2 両側のレディタイムラグ

両方のプレイヤーが30秒以上のスキルを待機しない場合、ジャージーは30秒のタイムアウトを与えることができます。

| ステップ | 処理 |
| --- | --- |
| 最初の30秒制限時間内にも誰も待機しません | 両方のプレイヤーに`注意` 1回ずつ課金し、再度30秒を与える |
| 2番目の30秒制限時間内に誰も待機しません | 双方の敗北でゲーム終了 |

<a id="floor-multiple-ready"></a>
## 5.3 複数のカードを同時にレディした場合

ゲームが指定した固有効果ではないのに、1枚のカードを見えないように隠すなどの方法で2章以上を同時にレディすると、次のように処理します。

- そのプレイヤーに`対応なし` 1回を課す
- レディではないものとして扱う
- ゲームの再開

<a id="floor-get-phase"></a>
## 5.4 ゲットフェイズ

- 30秒以内に手札にインポートするスキルを設定する必要があります。
- 30秒が経過すると、カードをインポートしないと見なされ、そのプレイヤーの行動が終了します。
- インポートしたカードは、相手が正確に確認できるように表示します。
- 手数が上限に達した状態でスキルをインポートした場合は、インポート後すぐに超過した長数だけ手札をリストに置きます。

<a id="floor-lumen-recovery"></a>
## 5.5 ルーメン・リカバリーフェイズ

- 処理する効果がある場合、フェイズ進入時に相手に効果処理があることを知らせます。
- 通知後、30秒以内に効果処理を宣言する必要があります。
- 30秒が経過すると、その効果は処理されていないと見なされます。

### 強制効果を処理していない場合

- 相手プレイヤーはジャージーに連絡できます。
- ジャージーは、ゲームに与える影響に応じて`注意`または`警告`を課すことがあります。

### 通知なしにフェイズが倒れた場合

効果があることを通知していない場合、または通知の前にすぐに次のフェーズアクションを実行してフェーズがスキップされた場合、ジャージーは帰責事由のあるプレイヤーに`注意`を課した後に効果処理を再度促します。

<a id="floor-records-and-state"></a>
# 6. 記録とゲーム状態の不一致



<a id="floor-notes"></a>
## 6.1 手書き

- 手札に持ってきた技やレディフェイズに使った技を別に記録する行為は禁止します。
- 体力とFP確認のための記録は許可します。
- スタミナとFP表示目的のアプリケーションの使用も許可します。

<a id="floor-hp-discrepancy"></a>
## 6.2 両側の体力記録が異なる場合

ゲームを一時停止してジャージーに連絡することができます。原文はレディフェイズにカードを公開した後、効果処理直前に記録の違いを確認する状況を例にとります。

### 記録を確認できる場合

1. ジャージーの監督の下、該当状況直前までに記録した体力を確認します。
2. 各プレイヤーの体力は、両記録のうちより低い値に設定されます。
3. その値でゲームを再開します。
4. 両プレイヤーに`警告`1回ずつ課金します。

> [!EXAMPLE]
> ある記録が`A 3700 / B 4300`、もう一方の記録が`A 3900 / B 4200`の場合、`A 3700 / B 4200`でゲームを再開し、両側に警告1回ずつ課金します。

### 記録を完全に確認できない場合

- 両方のプレイヤーの体力を2500に調整し、ゲームを再開します。
- 両プレイヤーに`警告`1回ずつ課金します。

<a id="floor-hand-limit"></a>
## 6.3 負の上限を超えた場合

- 手札の上限を超えると、すぐに超過した長さだけ手札を捨てます。ルーメンコンデンサーで捨てたカードはリストに入れます。
- これを守っていない状態がゲーム中に見つかったら`警告`1回を課し、すぐに超過分を捨てます。
- 程度がひどいとジャージまたは大会主催側が判断すると、そのゲームで`ゲームロス`が課されることがあります。

> [!WARNING]
> このフロアルールは、「即時」超過分を捨てると表します。別々の総合規則がステータス確認の時点をさらに細分化する場合は、両方の文書の優先順位を任意に決定するのではなく、最新の公式または阻止判断を確認する必要があります。

<a id="floor-match-time"></a>
# 7. 大会制限時間と時間終了処理



<a id="floor-default-match-time"></a>
## 7.1 基本的な試合時間

コンテストで別途時間を指定していない場合は、以下を適用します。

| 区分 | 試合方法 | 制限時間 |
| --- | --- | ---: |
| スイスラウンド | 単板戦 | ラウンドあたり30分 |
| 本線 | 単板戦 | ラウンドあたり30分 |
| 3・4ウィジョン | 単板戦 | ラウンドあたり30分 |
| 決勝 | 3版2 | ゲームあたり25分 |

<a id="floor-time-expiration"></a>
## 7.2 タイムアウトは終了してもゲームが終了していない場合

1. 現在処理中の効果があればその効果まで処理します。
2. 現在の体力を比較します。
3. 体力の高いプレイヤーが勝ちます。
4. 体力が同じ場合、現在優先権を持つプレイヤーが勝利します。

<a id="floor-simultaneous-zero"></a>
## 7.3 両方の体力が同時に0になった場合

- サドンデスゲームで勝敗を決めます。
- サドンデスで最終勝利したプレイヤーがそのゲームの勝者になります。
- サドンデスも引き分けであれば、そのゲームは双方の敗北で処理されます。

<a id="floor-sudden-death"></a>
## 7.4 サドンデス

フロアルールは、次の条件で新しいゲームを開始すると規定しています。

- 両体力1000
- 手札枚数最大
- 制限時間3ターン

> [!WARNING]
> フロアルール本文は「手札枚数最大」と「3ターン」のみ提示し、手札・リスト・サイドデッキの再構成や優先権の維持など詳細準備手順は説明しません。詳細なゲームの手順については、[総合規則書のサドンデス](./lumen-comprehensive-rules.md#rule-12-2-1)と最新の公式判定を一緒に確認してください。

<a id="floor-ranking-double-loss"></a>
## 7.5 決勝戦と順位圏の試合で双方の敗北が発生した場合

決勝戦、3・4上記決定戦など順位圏競技で双方敗北が発生した場合、次の順番で勝者を決めます。

1. スイス大戦戦績で勝手、勝点などがより優れたプレイヤーが勝利します。
2. 大会戦績も同じであれば、両プレイヤーの合意に応じてはさみロック、コイントース、譲渡などの方法で順位を決めます。

<a id="floor-participation"></a>
# 8. 結果報告・降伏・棄権・知覚



<a id="floor-result-report"></a>
## 8.1 対戦結果報告

- 結果を記録・報告・提出する方法は大会ごとに定めた方式に従います。
- 携帯端末または勝敗結果レポートを通じて両方のプレーヤーの署名または確認が必要な場合、一度提出した結果は回復できません。

<a id="floor-match-fixing"></a>
## 8.2 不正勝負操作（アビュージング）

- 意図的に勝敗を操作した事実が発見された場合、そのプレイヤーは戦績に関係なく、その大会で失格となります。
- 大会終了後に勝負操作が発見された場合、大会主催側の判断に基づき、次の措置を講じることができます。
  - 対戦結果と順位修正
  - 商品返品要求
  - 当該大会の永久出場停止等権利剥奪

<a id="floor-concession"></a>
## 8.3 降伏

ゲーム中に敗北を認めると、そのゲームで敗北したものとして扱います。

<a id="floor-drop"></a>
## 8.4 棄権

- 大会中に棄権しようとするプレイヤーはジャージまたは大会主催側に知らせ、大会から離脱することができます。
- 対戦相手が発表された後、棄権すると、そのゲームで敗北したものとして扱います。

<a id="floor-tardiness"></a>
## 8.5 知覚

対戦相手が発表された後、ゲーム準備をしなければならないが、そのテーブルにプレイヤーが表示されない場合は知覚で判断します。

| 知覚時間 | 処理 |
| --- | --- |
| ラウンド開始宣言後5分以内 | `警告` |
| ラウンド開始宣言後5分以上 | 対応ラウンド敗北 |

- 警告が3回累積すると、大会戦績に関係なく失格となります。
- 競技主催側の許可なしに席を外したり、他の対戦に影響を与えると、敗北や失格の不利益が発生することがあります。

<a id="floor-extra-time"></a>
## 8.6 追加時間

次の状況で、そのテーブルに追加時間を与えることができます。

- ジャージまたは大会主催側が事案を認めてプレイヤーが席を離れた場合
- プレイヤーがジャージにジャージや異議を申し立て、決定にかかる時間がゲームに影響を与えたと判断した場合

追加時間は、該当する問題に費やされた時間に1分を加えた時間です。

---

<a id="floor-rulings-and-information"></a>
# 9. ルール判断と情報確認



<a id="floor-ruling-call"></a>
## 9.1 ルール判断

- 競技中のゲームは、基本的に両方のプレイヤーがルールと効果を互いに確認して進行します。
- プレイヤー同士が判断しにくい、または意見の違いで紛争が発生した場合は、すぐにゲームを停止してジャージーに連絡する必要があります。
- ジャージを確認せずにゲームを続けると、その結果に対する責任は両方のプレイヤーにあります。
- 観戦者などゲームを進行しない人は、ルールの問い合わせや介入ができません。
- ジャージーは不正行為や誤ったルール・効果処理を発見すれば、別途問わず介入して修正を求め、ペナルティを課すことができます。

<a id="floor-opponent-card-check"></a>
## 9.2 相手のカード確認

以下の場合を除き、相手に手札のカード確認を求めることはできません。

- ゲットフェイズからインポートしたカード
- 効果で手札に持ってきたカード
- 相手の手札を見るカード効果
- 使用条件に応じた`対応なし`宣言をジャージ監督の下で確認する場合

強制的に手札の開示を求められたら、ジャージーに問い合わせることができます。

<a id="floor-cost-refusal"></a>
## 9.3 使用条件・コスト支払い拒否で対応なしを宣言した場合

- 使用コストの支払いを拒否して対応なしを宣言すると、相手プレイヤーはジャージ監督の下でそのプレイヤーの手札を確認できます。
- 確認の結果、技術の使用条件とコストを満たしている場合は、その技術を必ず使用する必要があります。
- 対応なし宣言しようとしたプレイヤーには、`警告`またはジャージーの判断によって、より厳しいペナルティが課されることがあります。

<a id="floor-mobile-device"></a>
## 9.4 携帯機器の注意事項

ゲーム中に別途メモをしたり、相手に画面を見せずに携帯電話・タブレットなどを操作してゲーム結果に影響を与えたとジャージまたは大会主催側が判断すると不利益が発生することがあります。

体力とFPを表示するためのアプリケーションの使用は許可されますが、その他の記録や操作は上記の規定により判断されます。

<a id="floor-penalties"></a>
# 10. ペナルティ



> [!IMPORTANT]
> 以下の例は、原文によって提示された代表的なケースです。実際のペナルティは違反の故意性、ゲームに及ぼす影響、繰り返し性、大会運営に及ぼす支障などを阻止または大会主催側が判断して適用します。このウェブページは自動的にペナルティを決定するツールではありません。

## ペナルティサマリー

| ペナルティ | 適用の趣旨 | 累積・結果 |
| --- | --- | --- |
| 注意 | すぐに正しい状態に戻すことができ、勝敗に影響を与えない、または特定のプレイヤーが有利にならない違反 | 注意3回累積時警告1回 |
| 警告 | 勝敗に影響を与える可能性があるが元に戻す違反、または注意に該当する違反の繰り返し | 警告 3回累積時該当大会・イベント失格 |
| ゲームロス | 重大な違反により当該ゲームの結果を認めることが不当と判断された場合 | 該当ゲームの敗北、程度に応じてより厳重なペナルティが可能 |
| 失格 | ゲームの信頼を失ったり大会運営に重大な支障を与える違反 | 受賞・商品除外及び順位修正可能 |
| 参加資格停止 | 公式大会・イベント参加を拒否または停止する必要がある重大な行為 | 公式告知後の参加拒否・停止 |

<a id="floor-caution"></a>
## 10.1 注意

ゲームの勝敗に影響を与えずにすぐに正しいプレイに戻すことができます。

注意が3回蓄積されると、警告1回が課されます。

### 原文の例

- 誤ってサイドデッキカード1を前面に公開
- 誤って手札1章を公開しました
- どのカードで発生した効果なのか、相手に正確に知らせない
- ブレイク後、サイドデッキでリストに補充する処理を次のフェーズにする

<a id="floor-warning"></a>
## 10.2 警告

ゲームの勝敗に影響を与えることができますが、正しいプレイに戻すことができる場合、または注意が蓄積された状態で注意に該当するルール・マナー違反を繰り返したときに課します。

警告が3回累積されると、そのコンテストとイベントで失格します。

### 原文の例

- 制限時間内にゲームが終了しないように意図的にスロープレイする
- 強制効果を意図的に無視して適用しない
- 技術効果を正しく処理せずに意図的に異なる方法で処理する
- 条件のため使用できない技術を使用する

<a id="floor-game-loss"></a>
## 10.3 ゲームロス

重大な違反が勝敗に大きな影響を与え、そのゲームの結果を認めることが不当であるとジャージーまたは大会の主催者が判断した場合に課すことができます。

違反の程度に応じて、より厳しいペナルティを受ける可能性があります。

### 原文の例

- 相手と相談してゲームの内容や結果を操作する
- 送信したデッキリストと実際のデッキの内容が異なる
- エラータが適用されたカードをエラータ移行効果として使用する
- 自分に有利な状況を作るためにジャージー判断に反するか、ルール違反を繰り返す

> [!NOTE]
> 同じ原文は、別途の「不正勝負操作（アビュージング）」節で意図的な勝敗操作が確認されれば、当該大会で失格とも規定しています。2つの条項を自動的に1つの結果にまとめないでください。

<a id="floor-disqualification"></a>
## 10.4 失格

重大な違反により、プレイヤーのゲームに対する信頼を失ったり、大会の運営に重大な支障が生じた場合に課せられます。

失格になると大会終了後も受賞・商品受領から除外され、順位が修正されることがあります。

### 原文の例

- カードまたはスリーブに意図的なマーキングをして区別可能な状態でゲームする
- 勝敗に大きく影響するほど反復的で悪意のあるスロープレイをする
- 相手をだますためにサイドデッキと手札を交換する
- デッキリストにないカードをこっそりリストや手札などに入れて使う
- 雪だるまですでにレディーなカードを別のカードに置き換える
- 脅迫などで勝負操作を強要する

<a id="floor-suspension"></a>
## 10.5 参加資格停止

参加資格停止が課されたプレイヤーは公式のお知らせを通じて公式主催大会・イベント参加が拒否または停止されます。

### 原文の例

- 他の参加者に危害を加える行為
- 犯罪行為を試みたり実行した行為
- 迷風洋俗に違反する行為

<a id="floor-checklist"></a>
# 11. 大会参加チェックリスト

## 参加者の準備

- [ ] 正式発売・許可カードのみ使用する。
- [ ] デッキの技カードプロテクターが同じで、裏面にカードを区別できない。
- [ ] カードやプロテクターにマーキングで見られる損傷・付着物・表示がない。
- [ ] デッキ枚数、サイドデッキ 枚数、開始手札を相手に確認させる準備ができている。
- [ ] 体力とFPだけ記録し、手札やレディカードを別にメモしない。
- [ ] レディ 10秒、ゲット 30秒、ルーメン・リカバリー効果宣言 30秒を確認した。
- []ルールの判断が必要な場合は、ゲームを停止してジャージーを呼び出します。
- [ ] 結果提出前の両方が内容を確認する。

## ジャージーコールが必要な代表的な状況

- [] 2人のプレイヤーのルールまたは効果の解釈が異なります。
- [ ] 体力・FP 記録が異なる。
- [ ]意図的な対応なし、スロープレイまたは不正行為が疑われる。
- [ ] カード・プロテクターマーキングの有無や補助具の使用可否を判断しなければならない。
- [ ]敗 公開または使用条件・コスト確認が必要である。
- [ ]プレイヤーが席を空けて追加時間が必要です。

# 캐릭터 계산기 패시브 표현안

2026-10-17. 신규 캐릭터 UI에만 적용합니다. 기존 계산기의 화면과 조작은 유지합니다.

## 공통 배치와 조작

- 이름·캐릭터 아이콘·별도 손패 헤더를 제거하고 손패 수를 HP 상자 오른쪽 위에 표시합니다. HP·FP·입력 버튼을 맨 위로 옮깁니다. 1P는 HP→FP, 2P는 FP→HP 순서로 중앙선을 기준으로 대칭입니다.
- 패시브 패널은 스크롤하지 않습니다. 낮은 가로 화면에서도 모든 조작이 패널 안에 들어가도록 전용 배치를 사용합니다.
- 배경과 원작 캐릭터의 명암 보호막을 줄이고, 1P의 배경 레이어만 좌우 반전합니다. 숫자 뒤의 작은 보호 영역은 유지합니다.
- 글자를 상시 나열하지 않습니다. 그림의 점등·개수·프레임으로 상태를 나타냅니다. 조작 이름·현재 수치·활성 여부는 스크린 리더에 제공하고 웹에서는 툴팁으로 확인합니다.
- 짧은 입력 섬광·잔광·회전은 0.4~0.6초입니다. 초기 로딩·복원·재접속·되돌리기에는 발동 연출을 재생하지 않습니다. 활성 상태의 약한 지속 장식은 현재 상태에 맞춰 표시합니다. 움직임 줄이기에서는 정적인 강조로 대체합니다.
- 수동 입력만 기존 액션으로 전달합니다. 연출로 HP·FP·패시브 수치를 추가 변경하지 않습니다.

## 우선 구현: 리타·타오·비올라

### 리타

- 빛의 루멘: 루멘콘덴서 결정 문양을 평소 어둡게 표시합니다. 누르면 섬광 후 점등됩니다. 다시 누르면 꺼집니다.
- 레기온: 실제 가디언·어쌔신·팔라딘 카드 그림을 각각 마름모에 담습니다. 선택한 한 곳만 원색과 밝은 프레임으로 표시합니다. 같은 곳을 다시 누르면 해제합니다.
- light_lumen 불리언과 rita_role 문자열(guardian / assassin / paladin / 빈 값)을 사용합니다. 효과 수치는 새로 자동 적용하지 않습니다.

### 타오

- 패널 양 끝에 흰색 양 바와 검정색 음 바를 각각 4칸씩 세로로 둡니다.
- 어느 빈 칸을 눌러도 아래에서 한 칸 증가합니다. 어느 켜진 칸을 눌러도 위에서 한 칸 감소합니다. 눌린 위치로 수치가 뛰거나 구멍이 생기지 않습니다.
- 4/4로 조화가 활성화되면 두 원이 회전하며 음양 문양을 이룹니다. 효과 선택 전에는 두 바를 잠그고, 음의 +1FP와 양의 +100DMG 중 하나를 고릅니다.
- 선택한 쪽을 밝게 표시하고 그 위에 선택한 효과만 씁니다. 선택 후에는 바 조작이 다시 가능해집니다. 같은 효과를 다시 누르면 선택이 해제되어 다시 고르게 됩니다.
- 조화는 기존처럼 양·음 모두 3 이상이면 유지하고, 어느 쪽이든 3 미만이면 효과와 함께 해제합니다. 해제 시 문양이 회전하며 사라지고 두 원으로 돌아갑니다.
- yang_counter, yin_counter, harmony, harmony_effect를 그대로 사용합니다. +1FP·+100DMG는 선택 상태의 표시이며 FP나 HP를 자동으로 바꾸지 않습니다.

### 비올라

- 실제 비올라 토큰에 있는 문양 3개를 사용합니다. 꺼진 문양도 배경과 구분되도록 윤곽을 남깁니다.
- 빈 문양을 누르면 왼쪽부터 한 개 증가하고, 켜진 문양을 누르면 가장 오른쪽 활성 문양이 하나 감소합니다.
- 켜질 때 짧은 섬광, 꺼질 때 보랏빛 잔광을 남깁니다.
- silver_counter의 0~3 값을 사용합니다.

## 2026-10-18 아이콘 이미지 품질 개편

기존 코드 도형 20종은 현재 화면에서 사용하지 않습니다. 10종의 생성 이미지와 10종의 원작 카드 크롭으로 교체했습니다. 리타·비올라의 기존 원작 카드 그림과 타오의 조화 조작은 유지합니다.

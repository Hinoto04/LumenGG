# CB02 번역·시뮬레이터 검증 (2026-10-23)

CB02 본편·프로모·챔피언십 팩의 수록 정보를 기준으로 확인했다. 희귀도별 인쇄 157개, 고유 인쇄 코드 72개이며, 게임 카드가 아닌 캐릭터/스킨 7개를 제외하면 서로 다른 게임 카드는 60종이다. 이 중 CB02 신규 원본은 29종이고 나머지 31종은 기존 카드의 재록이다.

## 번역

29종 모두 이름·효과·루비·보충 설명·키워드·검색어·숨김 검색어의 영문/일문 데이터를 저장소에 수록했다. 원문이 빈 항목은 빈 값을 유지한다. 기존 번역 카탈로그에는 필요한 번역이 있었지만 구형 CardTranslation 테이블에 신규 카드의 키워드 48개·검색어 16개와 재록 카드의 추가 60개 항목이 비어 있었다. 전체 124개(키워드 90개·검색어 34개)를 복구했다.

`common.0021_cb02_localization`·`common.0022_cb02_reprint_localization`과 `fill_missing_localization`은 누락된 값을 두 번역 저장소에 보완한다. 기존 편집 번역과 비활성 원문은 보존하고, 현재 한국어 원문이 캡처된 원문과 다르면 해당 필드를 건너뛴다. 마이그레이션 이후에 카드를 가져와도 복구 명령으로 적용할 수 있다.

## 실제 반영 결과

- 번역 마이그레이션 적용 완료. 신규·재록을 합쳐 누락 124개 필드를 보완했으며, 재실행 시 변경 0개다.
- 전체 455종/1,022개 능력의 게시 검증이 오류·경고 없이 통과했다. 기존 정의 재검증 451종과 현재 컴파일러로 재생성한 4종을 합쳐 455종 모두 결정적 검증을 통과했다.
- 새 활성 규칙: `2026.10.23-CB02` (이전 활성 규칙 `CB03`). 기존 대전은 원래 릴리스에 계속 고정되며 새 대전부터 새 정의를 사용한다.
- 내용 해시: `2187492a0c45c6c1218a4910c2d468cffc6d8ced9ac4f5e493ca7d699429f89b`.

전체 규칙을 게시하기 위해 오래된 저장 정의 4개도 기존 컴파일러로 재생성했다. 한국어 카드 원문은 변경하지 않았다.

# 계산기 화면 스타일과 배경 · 2026-10-19

기존 계산기는 그대로 유지합니다. 신규 캐릭터 계산기의 표시 설정으로 일러스트 / 깔끔하게를 제공합니다. 웹·앱의 시작 선택에는 기존 계산기, 캐릭터 UI 계산기, 깔끔한 UI 계산기가 있습니다. 두 신규 항목은 같은 `ui=character` 세션에 들어가며 기기별 표시 설정만 다릅니다.

## Android 배경 정렬

- 기존 Android 정적 Image에는 패널 크기가 명시되지 않았고, 캐릭터 높이는 전체 창 높이에서 계산했습니다. 웹의 패널 기준 cover/contain과 달라 그림의 크기·잘리는 부분·위치가 달랐습니다.
- 배경과 인물을 패딩이 없는 별도의 absoluteFill View 안에 배치합니다. 배경 Image는 그 레이어의 너비·높이 100%, cover·중앙 맞춤을 사용합니다. 패딩이 있는 자원 패널 자체에 100%를 지정해 생기는 가장자리 빈 띠도 방지합니다.
- 인물은 패널 너비 94%, 바깥쪽 -8%, 위 0 / 아래 -3%, contain, 1P 오른쪽 / 2P 왼쪽 맞춤, 불투명도 0.8입니다. 이 기준은 웹과 같습니다. 배경만 1P에서 좌우 반전합니다.
- 배경 원본 19장의 웹·앱 바이트를 비교합니다. 패널 종횡비에 따른 cover 크롭 차이는 정상이며, 같은 패널 크기로 비교하면 같은 원본 영역을 사용합니다.

## 밝기와 스타일

- 일러스트의 기본 밝기는 35%입니다. 웹 중앙 톱니바퀴의 화면 설정, 앱 계산기 설정의 화면 스타일에서 바꿉니다. 웹은 슬라이더, 앱은 ±10과 권장 밝기 버튼을 제공합니다.
- 0~100% 값을 사용하고, `#080d16` 보호 레이어의 불투명도를 `1 - brightness / 100`으로 설정합니다. 이 레이어는 배경·인물 위, HP·FP·패시브 아래에 있습니다. 아이콘·숫자·버튼은 어두워지지 않습니다.
- 깔끔하게는 그림 배경과 인물을 표시하지 않고 단색 패널·전용 래스터 아이콘을 사용합니다. 자원 위치, 입력 대기, 토큰 개수, 조건, 행동과 세션은 그대로입니다. 리타의 역할 버튼은 그림이 잘리지 않는 모서리가 둥근 사각형으로 표시합니다. 이오몽은 계속 빈 영역입니다.
- 깔끔하게에서는 지속 효과·섬광·패시브 발동 애니메이션을 재생하지 않고 밝기와 선택 테두리로 상태를 표시합니다. 일러스트는 기존 효과와 시스템 움직임 줄이기를 유지합니다.
- 설정 키는 `lumengg-calculator-appearance-v1`입니다. 웹 localStorage / 앱 preferences에 저장하며 서버 모델·대전 액션·공유 권한에 추가하지 않습니다. 공유 링크의 기존 `ui=character`와 최근 접속은 유지하며, 표시 설정은 각 기기에 저장됩니다. 알 수 없는 값은 일러스트·35%로 복구합니다.

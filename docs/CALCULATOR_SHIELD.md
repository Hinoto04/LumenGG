# 핀프 보호막 · 2026-10-20

핀프의 보호막은 한 턴 동안 쓰는 임시 체력입니다. 일반 턴 종료를 계산기가 추적하지 않으므로 사용자가 **보호막 초기화 버튼으로 직접 해제**합니다. FP 초기화와 타이머 종료로는 사라지지 않습니다.

- 기존·일러스트·깔끔한 계산기에 모두 적용합니다. 핀프의 패시브 영역에 `보호막+ / 초기화 / 보호막−` 세 버튼을 세로로 배치합니다. 다른 캐릭터에게는 표시하지 않습니다.
- 한 번에 ±100, 900ms 동안 연속 입력을 합산해 전송합니다. 누적 대기 수치는 버튼에 표시합니다. HP와 보호막 입력이 섞이면 서로의 순서를 보존합니다.
- 보호막이 있으면 실제 HP 오른쪽에 파란 `+NNN`을 표시합니다. 손패 제한·승패 판단은 실제 HP를 기준으로 합니다.
- 예: HP 5500, 보호막 300에서 피해 500 → HP 5300, 보호막 0. 피해 100 → HP 5500, 보호막 200.
- 보호막은 0 미만이 되지 않습니다. 총량에 별도 게임 상한을 추가하지 않습니다. 단일 API 변화량은 기존 HP 입력과 같은 ±50000 범위로 제한합니다.
- HP 회복은 보호막을 회복하지 않습니다. HP 되돌리기는 해당 피해에 흡수된 보호막도 돌려주며, 피해 이후에 추가한 보호막을 보존합니다.
- 초기화 전에 입력 중이던 변화는 순서대로 확정하고 보호막을 0으로 만듭니다. 이후 지연된 추가 입력이 다시 적용되지 않습니다. 전체 계산기 초기화·서든 데스 진입·새 세트·캐릭터 선택에서는 기존 패시브 초기화와 함께 0으로 시작합니다.

## 상태와 동작

기존 `playerN_passive_state` JSON의 `finf_shield.value`에 저장합니다. 테이블 변경이나 마이그레이션은 필요하지 않습니다. 구형 저장 데이터에 이 키가 없으면 0으로 취급합니다. 새 세션·카탈로그의 초기 상태에도 0을 제공합니다.

서버의 `shield`, `shield_reset` 액션을 웹, 모바일 공유, 파티 교전에서 공통 사용합니다. 관전자는 값을 볼 수 있고 조작할 수 없습니다. 모바일 로컬/오프라인도 같은 동작을 제공하고 재시작 후 수치를 복원합니다. 기존 일반 패시브 액션으로 이 전용 키를 수정할 수 없습니다.

피해 이벤트에는 보호막의 이전/이후 값과 흡수량을 함께 저장합니다. DB 이벤트와 Redis 대기 이벤트 양쪽의 되돌리기에 적용합니다. 기록에도 흡수·복원을 표시합니다.

웹의 낙관적 계산과 앱 로컬 계산은 `mobile/src/calculator-shield.ts`를 공유합니다. `scripts/build_calculator_visuals.cjs`가 웹용 `calculator-shield-model.js`를 만듭니다. 실제 서버 계산은 `battlelog/services.py`와 `battlelog/shields.py`에 있습니다.

플레이 스타일
초반, 중반 (체력 3000~5000)
~ -4FP 상황 : 수비 기술, 파워풀 스윕
-3 ~ -1FP 상황 : 패니 슬라이드, 수비 기술, 백 샷, 인스턴트 스매시
뉴트럴 상황 : 가능한 차지를 사용하지 않고, 커팅, 패니 슬라이드, 수비기술
+1 ~ +3FP 상황 : 커팅, 패니 슬라이드, 배드맨 퍼니시, 기어체인지
+4FP ~ 상황 : 차지를 사용하며, 차징 스매시, 패니 슬라이드, 루트아스트라, 커팅

겟 페이즈 시에는 현재 상황에 사용할 카드를 미리 손으로 가져오거나 현재 상황에 맞는 카드가 충분히 마련되어 있다면 콤보 카드를 가져옴

파워풀 스윕 브레이크 시 루트킷을 보충
캐치는 8FP 이상 캐치가 가능할 때, 루트킷 캐치가 가능하면 할 것

후반 (체력 ~1500)
뉴트럴 상황 : 초중반과 비슷하게 행동
+1 ~ +3FP 상황 : 초중반과 비슷하게 행동
+4FP ~ 상황 : 올 인 차지 후, 차징 스매시, 스톰브링거, 패니 슬라이드

파워풀 스윕 브레이크 시 루트킷을 보충
캐치는 8FP 이상 캐치가 가능할 때, 루트킷 캐치가 가능하면 할 것

콤보 루트
초반 손패 부족 시
2 루트아스트라 -> 3 하이 볼티지

손패 충분할 시
2 패니 슬라이드 -> 3 배드맨 퍼니시 -> 4 루트아스트라 -> 5 하이 볼티지 -> 6 그라인더 슬링

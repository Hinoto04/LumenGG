- 코드만으로 단정할 수 없고 룰 해석에 따라 결과가 달라지는 항목만 기록한다.

- 동일한 재정은 카드별로 중복 작성하지 않고 공통 질문 하나로 묶는다.

[Q-AUTO-001] 캐치로 사용한 배드 캐쳐(ST6-005)의 ‘1콤보’ 처리
- 상태: 답변 반영 완료
- 관련 카드: ST6-005 배드 캐쳐
- 관련 재정: Q&A 128, 511, 580, 588, 625
- 상황: 배드 캐쳐를 배틀의 시동 기술이 아닌 캐치 기술로 사용했고, 히트 판정 문구가 ‘콤보’인 경우이다.
- 질문: 이 경우도 카드의 ① ‘콤보 시 이 기술이 1콤보인 경우’를 만족하여 은연 1개를 소모하고 리스트의 홀수 속도 공격 기술을 획득합니까? 아니면 ①은 배틀 판정으로 열린 1콤보에서만 발동합니까?
- 현재 구현: 배틀과 캐치에서 인쇄된 콤보 판정으로 콤보 타임을 열 때 모두 `combo_judgment=true`, `combo_number=1`을 전달한다. 캐치 경로는 `use_context=catch`로 구별하면서도 ①의 은연 1개 소모와 홀수 속도 공격 기술 강제 획득을 동일하게 처리한다.
- 재현 근거: 실제 캐치 기술 파이프라인에서 배드 캐쳐를 9속도로 사용해 `사용 시 → 캐치 시 → 히트 시 → 사용 후 → 콤보`를 통과시켰다. 은연 3개에서 ②가 먼저 1개, 콤보 시작 ①이 다시 1개를 소모해 선택 시점에 1개가 남았고, 리스트의 홀수 속도 공격 기술만 강제 선택지에 표시되어 패로 이동했다.
- 답변: 캐치로 히트 판정이 콤보인 기술을 적중시켜도 콤보 타임은 발생한다. 따라서, 1콤보로 콤보 타임을 시작할 수 있다.
- 확정 일자: 2026-08-27
- 반영 상태: 완료

[Q-AUTO-002] 럭키 데이즈로 소원의 가온을 배치할 때 패 버리기와 복귀의 순서
- 상태: 답변 반영 완료
- 관련 카드: DFR-AT-018 럭키 데이즈, ST4-SS3 소원의 가온, ST4-PS1 「예고」
- 관련 재정: Q&A 101, 484, 695
- 상황: 자신의 체력이 2000 이하이고 패가 5장 이상인 루멘 페이즈에 럭키 데이즈 ①을 발동해, 소원의 가온을 포함한 예고장 3장을 사이드 덱에서 루멘 존에 배치한다. 럭키 데이즈에는 그 후 패가 4장이 되도록 버리는 처리가 남아 있다.
- 질문: 예고장 3장을 배치한 직후 패를 버리기 전에 소원의 가온의 ‘자신의 패가 5장 이상이면 이 예고장을 사이드 덱으로 보낸다’가 적용되어 가온이 즉시 돌아갑니까? 아니면 럭키 데이즈 ① 전체를 해결해 패가 4장이 된 뒤 상시 조건을 확인하므로 가온이 루멘 존에 남습니까?
- 현재 구현: 럭키 데이즈의 예고장 이동과 패 버리기를 하나의 효과 단위로 처리하고, 그 안에서 발생한 카드 이동·버리기 유발은 전체 명령 완료 뒤 해결한다. 따라서 패가 4장이 된 상태에서 가온의 조건을 확인하여 가온은 루멘 존에 남는다.
- 재현 근거: 실제 루멘 페이즈 파이프라인에서 패 6장과 가온을 포함한 예고장 3장을 사용했다. 이동 기록은 `예고장 3장 루멘 이동 → 패 2장 버림` 순으로 남고, 이후 가온 조건을 검사했을 때 패가 4장이므로 복귀 효과는 해결되지 않았다. 최종 상태는 예고장 3장, 패 4장이다.
- 답변: 소원의 가온의 상태 확인은 효과 단위의 종료 후 확인한다. 따라서, 럭키 데이즈의 효과를 완전히 처리한 후 소원의 가온의 조건을 확인하므로, 즉시 복귀처리는 수행하지 않는다.
- 확정 일자: 2026-08-27
- 반영 상태: 완료

[Q-AUTO-003] 팜므파탈과 매혹의 리커버리 은연 소모 순서
- 상태: 답변 반영 완료
- 관련 카드: CB01-AT-020 팜므파탈, AWL-SP-003 매혹
- 관련 재정: Q&A 139, 140, 143, 220, 225, 376, 383, 439, 564, 659, 666
- 상황: 팜므파탈과 매혹이 모두 자신의 루멘 존에 있고, 리커버리 페이즈 시작 시 은연 카운터가 정확히 2개다. 두 카드 모두 같은 타이밍에 은연 카운터 1개를 강제로 소모한다. 매혹은 자신의 소모 처리 후 은연 카운터가 없다면 브레이크한다.
- 질문: 같은 플레이어가 두 강제 효과의 해결 순서를 선택할 수 있으므로 매혹을 먼저 해결해 은연을 2→1로 만든 뒤 팜므파탈을 해결해 1→0으로 만들면, 매혹은 브레이크되지 않고 은연 0개인 상태로 다음 턴까지 남는 것이 맞습니까? 아니면 리커버리의 두 소모가 모두 끝난 뒤 매혹의 브레이크 조건을 다시 확인하거나, 정해진 처리 순서가 있어 반드시 브레이크합니까?
- 현재 구현: 동일한 공개 강제 효과의 순서를 플레이어가 선택한다. 매혹을 먼저 해결하면 매혹은 은연 1개가 남은 시점에 브레이크 조건을 통과하지 않고, 이후 팜므파탈이 마지막 1개를 소모해도 매혹의 조건을 다시 확인하지 않으므로 루멘 존에 남는다. 반대로 팜므파탈을 먼저 해결하면 매혹이 두 번째로 은연을 1→0으로 만들고 즉시 브레이크된다.
- 재현 근거: 실제 리커버리 페이즈 파이프라인에서 팜므파탈과 매혹, 은연 2개를 배치해 두 순서를 각각 결정적으로 재실행했다. `매혹 2→1 → 팜므파탈 1→0`에서는 두 카드가 루멘 존에 남고, `팜므파탈 2→1 → 매혹 1→0`에서는 매혹만 브레이크됐다.
- 답변: 동일한 공개 강제 효과이기 때문에 플레이어의 선택에 따라서 달라지는게 맞다. 플레이어가 매혹의 효과를 먼저 선택하면 처리후 은연이 1 남기때문에 매혹의 브레이크가 이루어지지 않고, 팜므파탈의 효과를 먼저 선택하면 매혹의 처리 후 은연 카운터가 남지 않으므로, 매혹이 브레이크된다.
- 확정 일자: 2026-08-27
- 반영 상태: 완료

[Q-AUTO-004] 작열대선풍의 콤보 시 자기 브레이크와 사용 시·데미지 처리
- 상태: 답변 반영 완료
- 관련 카드: CRS-AT-006 작열대선풍, CRS-PS-001 나찰염희
- 관련 재정: Q&A 523
- 상황: 작열대선풍을 콤보 기술로 사용하면서 ②를 적용해 그 작열대선풍 자체를 브레이크한다. 이 카드에는 별도로 ① 사용 시 패 1장 브레이크가 있으며, 콤보 기술로서 처리할 데미지도 남아 있다.
- 질문: ② 콤보 시 자기 브레이크를 먼저 해결한 뒤에도 ① 사용 시 패 브레이크, 콤보 데미지, 사용 후 처리를 계속 수행합니까? 아니면 ②로 카드가 배틀 존을 떠난 시점에 해당 콤보 기술의 나머지 사용 처리가 중단됩니까?
- 현재 구현: 콤보 기술은 `사용 시 → 콤보 시 → 콤보 창 → 데미지 → 사용 후` 순서로 해결한다. ①의 패 1장 브레이크를 먼저 처리한 뒤 ②를 선택하면 작열대선풍을 브레이크하지만, 해당 명령의 `continue_resolution`에 따라 저장한 카드 정보로 콤보 데미지를 처리하고 후속 콤보의 합법성을 다시 검사한다.
- 재현 근거: 실제 2·3콤보 엔진 경로에서 2콤보 작열대선풍의 ① 대상 선택이 ② 발동 선택보다 먼저 열렸다. 패 1장과 원본이 모두 브레이크된 뒤에도 작열대선풍 500, 후속 기술 400의 합계 900 피해가 처리됐고 `combo_interrupted(source_card_left_battle)`는 발생하지 않았다. 나찰염희와 ②가 자기 브레이크에 각각 반응해 불씨도 총 2개 얻었다.
- 답변: 사용 시가 콤보 시보다 우선 해결되기 때문에, 1의 효과는 항상 작동한다. 콤보 시의 발동 후, 이 카드가 브레이크되어 배틀 존을 떠나도 상대에게 데미지는 주며, 콤보 또한 이후 더 이을 수 있다.
- 확정 일자: 2026-08-27

[Q-AUTO-005] 피의 만찬의 ‘콤보에 사용한 기술’에 시동 기술 포함 여부
- 상태: 답변 반영 완료
- 관련 카드: PMP-AT-009 피의 만찬
- 관련 재정: Q&A 627
- 상황: 배틀 판정으로 콤보 타임을 연 1콤보 시동 기술 뒤에 피의 만찬을 2콤보로 사용하고 콤보 타임을 종료했다. 콤보에는 화면상 시동 기술과 피의 만찬 두 장이 사용됐다.
- 질문: ② ‘콤보에 사용한 기술 1장당 체력 100을 회복한다’의 장수에 콤보 타임을 발생시킨 1콤보 시동 기술도 포함하여 200을 회복합니까? 아니면 콤보 타임에 추가로 사용한 2콤보 이후 기술만 세어 100을 회복합니까?
- 현재 구현: 일반 콤보 타임은 처음에 합법적인 2·3콤보 두 장을 반드시 함께 제시해야 하며 한 장만 추가한 뒤 종료할 수 없다. 콤보 종료 컨텍스트에는 기존 추가 카드 수인 `combo_used_count`와 별도로 시동 기술까지 중복 없이 센 `combo_total_used_count`를 제공하고, 피의 만찬 ②는 전체 장수를 사용한다.
- 재현 근거: 시동 기술 뒤 피의 만찬을 포함한 2·3콤보를 사용한 최소 합법 콤보에서 전체 사용 기술은 3장이고 체력 300을 회복했다. 시동 기술과 추가 기술 4장인 경우에는 500을 회복했으며, 상대 콤보 종료에는 회복하지 않았다. 기존의 시동 기술+피의 만찬 한 장만 사용한 재현은 코어 규칙상 시작할 수 없는 콤보로 교체했다.
- 답변: 1콤보 시동 기술 또한 이번 턴에 콤보에 사용한 기술이므로 포함한다. 배틀 판정으로 콤보를 연 1콤보 시동 기술 뒤에 피의 만찬을 2콤보로 사용하고 콤보 타임을 종료하는 것은 불가능하다. 콤보 타임에 진입 후 최소 2콤보를 추가로 이어야 한다.
- 확정 일자: 2026-08-27
- 반영 상태: 완료

[Q-AUTO-006] 달빛광휘의 히트와 콤보 판정이 겹칠 때 리커버리 FP 예약 횟수
- 상태: 답변 반영 완료
- 관련 카드: CB03-AT-012 달빛광휘
- 관련 재정: 연결된 카드별·일반 Q&A 없음
- 상황: 하이 텐션 상태의 달빛광휘가 배틀에서 히트하고, 인쇄된 히트 판정 ‘콤보’로 콤보 타임도 연다. 카드 문구는 ‘히트/카운터/콤보 시, 이번 턴 리커버리 페이즈에 5FP를 얻는다’이다.
- 질문: 한 번의 배틀 판정에서 히트 시와 콤보 시가 모두 발생했으므로 리커버리 FP +5를 두 번 예약해 총 10FP를 얻습니까? 아니면 슬래시로 묶인 하나의 효과가 같은 카드 해결 중 한 번만 발동해 총 5FP만 얻습니까?
- 현재 구현: 달빛광휘 ①에 턴당 1회 사용 제한 키를 부여했다. 같은 턴에 히트·카운터·콤보 조건이 연속으로 들어와도 먼저 발생한 조건에서만 리커버리 FP +5를 예약하며, 이후 조건은 사용 제한에 의해 다시 발동하지 않는다. 다음 턴에는 사용 횟수가 초기화된다.
- 재현 근거: 하이 텐션 상태에서 히트 이벤트 직후 같은 달빛광휘의 콤보 이벤트를 연속 실행해도 예약 효과와 `cb03-at-012-n1` 해결 기록이 각각 1개만 생성됐고, 리커버리에는 정확히 5FP만 얻었다. 히트·카운터·콤보 각각을 단독으로 실행한 경우에는 모두 정상적으로 한 번 예약했다.
- 답변: 번호가 매겨진 각각의 효과는 한 턴에 한 번만 발동한다. 따라서, 히트 시/콤보 시가 모두 만족되는 경우, 먼저 발동되는 히트 시 발동 이후 콤보 시에는 이 효과가 발동하지 않는다.
- 확정 일자: 2026-08-27

[Q-AUTO-007] 시크릿 타임(에라타) 뒷면 배치와 무작위 뒷면 카드 캐치
- 상태: 답변 반영 완료
- 관련 카드: UNC-AT-027 시크릿 타임 (CB04-AT-016 재록, 에라타 적용)
- 관련 재정: 에라타 이후 텍스트에 연결된 Q&A 없음. 에라타 이전 효과 기준 Q&A 59, 67, 111, 112, 113, 349, 350, 351, 353, 354, 544는 비밀 카드·속도 선언 처리에 관한 것이어서 새 정의의 근거로 쓰지 않았다.
